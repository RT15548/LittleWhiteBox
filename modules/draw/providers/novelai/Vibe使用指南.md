# NAI Vibe 使用指南

> 适用：NovelAI 生图（V4 / V4.5）。本文说明 Vibe 的数据结构、勾选规则与常见问题。
>
> 核心原则一句话：**勾选才是生成依据，组只是快速套用的模板。勾了就带，不勾就不带，与是否点保存无关。**

## 一、基本概念

- **单张 Vibe**：一张参考图 + 各模型对应的编码（encoding）+ 信息提取档位。
- **Vibe 组**：一份「单张 Vibe + 勾选状态 + 强度」的命名快照，作用是**快速套用模板**；套用时组成员会被拷贝为当前勾选，之后随时可改，改了即时生效，组快照本身不变。
- **Vibe 库**：全局资源，保存所有单张与组；图片和编码都存这里，不存进预设。
- **参数预设（画师串预设）**：保存一份勾选+强度快照 `selections`（以及来源组标识 `groupId`）。**保存的永远是保存那一刻的勾选状态**——勾着保存就一直带，不勾保存就一直不带，切换预设来回互不干扰。

## 二、前置条件

1. 模型必须是 V4 Curated / V4 Full / V4.5 Curated / V4.5 Full，否则 Vibe 不参与生成。
2. 需要可用的 API Key。
3. **编码消耗 Anlas**：每张参考图在每个模型下首次使用都要调用 `/ai/encode-vibe` 编码；同一模型编码成功后会缓存，不重复扣费。换模型需要为新模型重新编码。

## 三、操作流程

1. 在「参数预设」页的 Vibe 区域点「上传参考图」，图片入库并自动勾选，**上传不会自动编码**。
2. 勾选需要参与生成的图，拖动强度（0～1，默认 0.6）。
3. 「信息提取」为 0～1 连续滑杆（对齐官方，默认 1）。修改后该图所有模型编码作废，需手动点「点击编码」重新编码。编码只在用户手动点击时发起，避免误扣点数。
4. 需要复用组合时：
   - `＋` 把当前勾选另存为新组；
   - `💾` 无选中组时＝另存新组，有选中组时＝把当前勾选覆盖进该组快照；
   - `✎` 重命名、`🗑` 删除组（组内单张仍保留）。
5. 组可导出为 JSON（含原图与各模型编码），换机导入后无需重新花点数。

## 四、生效规则（核心）

### 1. 勾选即时生效

勾选、取消勾选、改强度、选组、存组、删图后，会在 300ms 内**静默写回当前参数预设并持久化**，不需要再点参数预设的「保存」。切换预设前会先强制写回旧预设，不会串到新预设。参数预设的「保存」按钮也只是把当时的勾选再存一次，不会额外清空或改变勾选。

### 2. 生成时以勾选快照为准

生成时读取的是预设里保存的勾选快照 `selections`：`enabled: true` 且已编码的项才注入请求；不勾选（`enabled: false`）、库里已删除、未编码的项一律不注入。不存在「不勾选仍然带 Vibe」的情况。

仅一种历史数据例外：旧版本组模式不落勾选记录（`selections` 为空数组）。此类预设第一次打开设置面板时会自动灌入组成员勾选，之后完全按新规则走。

### 3. 保存的语义

| 动作 | 写到哪 | 什么时候用 |
|---|---|---|
| 勾选/取消勾选/改强度 | 当前参数预设（即时静默写回） | 日常使用，改完即生效 |
| 预设「保存」按钮 | 当前参数预设（含当时勾选快照） | 确认落盘，行为与即时写回一致 |
| `＋` 另存新组 | Vibe 库新增一个组快照 | 想把当前勾选组合留存复用 |
| `💾`（有选中组） | 覆盖该组的成员快照 | 想更新组模板；引用它的其他预设不受影响 |

### 4. 情景对照表

| # | 情景 | 结果 |
|---|---|---|
| 1 | 勾选 A，不保存直接生成 | ✅ 带 A（已即时写回预设） |
| 2 | 取消勾选 A，不保存直接生成 | ✅ 不带 A（取消即写回） |
| 3 | 勾选 A+B，保存为组后生成 | ✅ 带 A+B（存组同时绑定当前预设） |
| 4 | 勾选 A 保存预设 P；切到无 Vibe 的预设 B 再切回 P | ✅ P 仍带 A |
| 5 | 取消勾选后保存预设 P；切到 B 再切回 P | ✅ P 一直不带 Vibe |
| 6 | 套用组「G1」后取消全部勾选，直接生成 | ✅ 不带任何 Vibe（组只是模板，勾选才是依据） |
| 7 | 套用组「G1」后自行勾选 A、取消 B，直接生成 | ✅ 带 A、不带 B（即时生效，无需存组） |
| 8 | 两个预设分别保存不同勾选，来回切换 | ✅ 各自带各自的快照，互不干扰 |
| 9 | 组模式（旧数据，从未打开过新版面板）直接生成 | ✅ 回退组成员（首次打开面板后会转为新快照） |
| 10 | 预设勾了 A，但 A 未编码/已删除 | ✅ 出图但不带 A，不扣编码费，弹提示列出未编码项 |

## 五、未编码与失败降级

- 编码只能由用户在设置页手动点「点击编码」发起；**生成时不会自动补编**，杜绝误扣编码费。
- 生成时发现当前模型缺少编码：**该张 Vibe 不应用、不扣编码费，整批继续出图**，并弹提示列出未编码项，提醒先点「点击编码」。
- 手动编码失败（最常见是 Anlas 不足 402，其次是网络/端点问题）时按钮保持「点击编码」，可稍后重试。
- 用户主动取消时正常中断，不按失败处理。
- 换模型后若无该模型编码：图仍会生成，只是不带 Vibe。

## 六、常见问题

- **换了模型后 Vibe 没效果**：新模型缺少编码，点「点击编码」即可；无 Anlas 时该张会被跳过，不扣编码费。
- **调强度要不要重新编码**：不用。强度在生成时随请求发送；只有改「信息提取」才需要重新编码。
- **不勾选了为什么还带着 Vibe（旧版本行为）**：旧版本组模式下勾选改动是临时草稿、生成跟随组快照，导致不勾仍带。当前版本已修复：勾选即时生效，取消勾选即不带。若某预设从未打开过新版设置面板，属旧数据回退（上表情景 9），打开面板一次即转为新快照。
- **套用组后改勾选，会影响组吗**：不会。组快照只在 `💾` 覆盖或 `＋` 另存时更新；其他引用同组的预设也不受影响。
- **切预设后 Vibe 丢了**：当前版本勾选/选组时已即时写回，无需手动保存；如遇到丢失请确认没有在切换前刷新页面。
- **图片裂开/找不到**：Vibe 原图存于全局库，清理缓存或换机导入时应带上导出 JSON。

## 七、相关代码

- 编码与生成前准备：`novel-draw.js` → `encodeVibeReference`、`ensurePresetVibeReady`
- 预设 Vibe 与快照：`novel-draw.js` → `normalizeVibeLibrary`、`normalizePresetVibe`
- 预设保存/加载：`novel-draw.html` → `collectParamsPreset`、`applyParamsPreset`
- 即时绑定：`novel-draw.html` → `flushVibeBinding` / `persistVibeBinding`
- 导入导出：`cloud-presets.js`、`novel-draw.html` → `handleVibeImportFiles`
