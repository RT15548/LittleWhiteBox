# 这间审理室外面

雾港靠装卸、驳运和货代吃饭。谁都认识谁，少盖一个章、替人递一页纸，往往会被说成「行个方便」。这一次，有人把未申报货物记在无关货主名下，三名经手人却各自把责任推向别处。

## 三号泊位调度室与雨棚

调度室里堆着舱单、提货票与值班记录，墙角的旧打卡钟咔哒作响。外面的雨棚挡不住斜雨，来往装卸工习惯在那里躲雨、等叫号。纸张一离开干燥的抽屉，边角很快就软了。

## 驳船甲板与四号货舱

扣押货物起自舵楼夹层。甲板带着油污，绳索浸透江水；四号货舱的舱壁另有待勘验的痕迹。舷梯窄，只容一个人侧身通过，走动时能听见水在船壳外轻拍。

## 泊位后侧的住所

一排铁皮宿舍贴着仓库后墙，屋里有床铺、工作服和带锁的小柜。夜班的人把休息与工作挤在同一小片地方，门一开就有潮衣服与旧烟的气味。
