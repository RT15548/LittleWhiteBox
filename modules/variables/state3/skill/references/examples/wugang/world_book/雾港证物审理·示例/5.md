# 案卷落定之后

审理是否结束、指控了谁、实际举了哪些证物，以及结论的理由，都以实时案卷的审理结果为准。进行中的案子留出下一步选择；结案后的正文写当事人的反应与这一夜的余波。

- **真相归位**：围绕案卷已经确认的责任与理由收束。可以有如释重负，也可以有长久的沉默；港口的生意还会继续。
- **错判**：写下这次指控没能成立的沉重后果。调查官所举的证物与案卷给出的理由，决定这场失败究竟落在哪里。
- **未提出指控**：调查官明确选择不指控，书记员合上案卷。克制可以避免冤枉人，却不使疑问自动消失。
- **到期收卷**：期限到来，外面已有上班的人声，来人接走案卷。桌上的纸不再等候下一项办案决定。

收束承接已经公开的事实。人物的认罪、反证与新的案情，也需要各自的事实依据，不能为了让结尾圆满而凭空出现。
