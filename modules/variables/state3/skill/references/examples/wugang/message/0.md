午夜，雾港三号泊位。

铁皮顶棚上的积水一滴一滴砸下来，声音在空荡的审理室里被放大。你面前是一张从仓库搬来的长桌，桌上摊着一本硬壳证物册，一盏裸灯泡悬在头顶。缉私队员把任命书推过来，薄薄一页纸，落款处连公章都没来得及盖齐。

「临时调查官。」他把话咬得很清楚，「早八点，货运公司的律师就到。我们需要一份能站得住脚的指控，不是随便找个人顶上。」

十二箱未申报的精密轴承，是入夜后从驳船舵楼夹层起出的。货就在隔壁，问题却藏在纸上：事后补填的舱单，把货记到了一个不相干的名字底下。

门被推开三次。

先是**祁修远**，泊位调度长，衬衫扣到最上面一颗。他站在桌边没有坐下，语速很快：「舱单归档是押运那边送的，我只按规程签字。这种操作失误，你们该去问船上的人。」

然后是**罗阿九**，驳船押运，手上有机油洗不掉的痕迹。他往椅背上一靠，半天只说了句：「我在船上睡觉。你们起货的时候我才醒。」

最后是**温仪**，货代代表，唯一一个还穿着外套的人。她坐下后先看表，再抬眼看你：「有些事，深究下去对谁都没好处，调查官。」

夜班看守**老陈**坐在门边，把湿帽子攥在手里。年轻的书记员抱来登记簿，先把空白的证言页压平，又翻开现场目录。

「还有八小时。现场先封着，证物还没取回来，正式证言也还没录。」他把笔递给你，「先去哪一处，还是先请哪位开口？」

证物册预留的编号底下都空着。雨声没有停，桌边的人也都在等你说第一句话。
