三楼的门半开着，“解铃会”的牌子刚擦过，水痕还没干。

唐圆从前台探出头，把一串钥匙和一本新的登记簿推到桌边：“钥匙都在这儿。账上六千，今天约了两位来面谈。”她翻开登记簿，会员那一栏还是空白，又把笔横放在上面，“先认识人，谈好了再往这儿写。”

走廊里，沈知微正把一把椅子往旁边挪，给门口多留出一点地方。三间互助室都收拾好了，桌上摆着纸杯，窗户开了一条缝。

“第一次来，多半会先问这里安不安全。”她合上手里的笔记本，走到前台，“我可以陪你面谈，也可以先带你看看房间。”

楼下传来脚步声，在这一层的拐角停了停。唐圆看了一眼钟，压低声音：“应该是第一位到了。现在请进来，还是你先跟我们聊聊？”
