# 角色卡界面的视觉诊断

从玩家指出的那一幕看起：眼前什么最抢眼，什么反而找不到？按对应症状动手，保留作者选定的画风、原有行动和剧情反馈。

| 玩家看到什么 | 怎么找问题、怎么改 |
| --- | --- |
| 太花 | 找出最亮的几处，逐个看颜色表示什么。背景渐变、标题渐变、按钮外发光都在抢眼时，先收掉普通控件的光和装饰色。场景里真正报警的灯仍然要醒目；正文和按钮文字仍要看得清。 |
| 太挤 | 看标题离自己的内容是否反而比离上一组更远，同一件事是否被拆进好几层框。把相关内容放近，给下一组腾出间隔。手机上可把偶尔查的资料收进有名字的入口，玩家做决定要看的代价留在选项旁。 |
| 没重点 | 把画面缩小，或眯眼看：第一眼落在哪？若读信时先看到的是旁边的状态栏，先减弱状态栏的底色、边框或占地，再看信是否自然成为主角。若几条剧情选项本来平等，就让整组选项突出。 |
| AI 味重 | 看换成另一张卡的名字后，哪些东西依旧处处适用：每栏都带 ✨ 和空泛副标题、每项都是一样大的「图标＋标题＋一句话」卡片、静止的数字也反复呼吸。删掉无信息的标签，让同类条目回到列表，把有辨识度的细节留给这张卡真正用得到的地方。 |

改完回到同一幕，用原来的正文和选项再看一眼。问题消失就停，不顺手重做其他区域。
