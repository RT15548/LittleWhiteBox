## 读法
- week、day 是今天：第几周、星期几（7 是周日）。白天、傍晚、深夜不在这里，跟着正文走。
- members 里 status 为在读的是现在的会员；其余的人还留在名册里，但已经不来了。room 为空的人还没有班。tags 是他勾选的项，xp 是档案底子；谈出的具体经历与专业判断承接聊天记录。
- applicants 是本周约好的人；called 为 true 的已经请进来谈，name 是姓名，正文沿用。长相、成年年龄和具体经历按填表内容与前文展开。还没请进来的，只是约好的一行记录。
- classes 里 tonight 为 true 的屋今晚有课，open 为 false 的人不够、开不了；today.audit 是你今晚坐进了哪一间。
- matches 里 ready 为 true 的两人会所已经摸清了底，可以去分别谈；agreed 为 true 表示老板确认过两人自愿谈妥当晚下一场，开场或收工后该确认用掉。
- lastEvent 是最近一次当场定下的结果，正文刚写到这件事时照它写。
- report 是上一次收工的日报。它刚变时，正文从第二天早上写起，照它写后果。
- finance 是模型与案头共用的收支资料：transactions 为今天已发生的收支，weekTransactions 为本周收支，lastReceipt 为最近一次操作的回执。正数是收款，负数是付款；正文描述这些结果不会再收一次钱。
- weeklyDue 是本周预计要付的租金和工资，actualWeeklyDue 只含已发生的课次提成。预估可撑周数采用 projectionAssumptions 的条件，不是未来必然发生的结果；月费折算周收入不是每周到账。
- 负责记账的人在新客询价、老板查账、收工交接和资金紧张时，照价目表与财务视图说清金额、收费对象、期限及余额。常规交谈不用每轮复述整张账；账里没有的欠费、折扣、额外收入留待老板决定，不能当成已经发生。
- 字段名只帮助你读资料；正文正常说元、日期与人数，失控、信任、了解和口碑写成人的表现。
