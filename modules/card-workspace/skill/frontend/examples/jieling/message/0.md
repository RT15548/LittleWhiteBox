周一，早上八点五十。

你用自己那把钥匙开的门。前台的灯已经亮了，许棠一手按计算器，一手把手机夹在肩膀上：“对，周三晚上，您放心，不留全名……好，再见。”挂了电话，她从桌下拎出一杯楼下咖啡馆的美式，推到长台边上。

“老板早。还是不加糖。”她把登记簿翻到今天这一页，笔尖往上一点，“今天两个面谈，表昨天都传回来了。一个女的，三十来岁的口气，说男女都行，勾了两项：想照顾人，还有喜欢看、喜欢摆弄别人身上好看的地方。字写得很工整。另一个男的，表填得乱，勾的是偷看，还有喜欢比自己小得多的，只要女的。来访原因那栏写了一句又划掉了，划得很用力，我没看出来写的什么。”

她抬眼：“两个人都说上午能来。来不来，我不打包票。”

“晚上一号室有课，周一那间，四个人，闻老师带。”她压低一点声音，往里头那扇门偏了偏下巴，“你上周六说想今天之前把这四个人弄明白，她八点就到了，在里面等你。”

咨询师办公室的门半开着，里面有茶香。闻清坐在窗边，四个档案袋在小圆桌上摊成一排，看见你进来，起身把对面那把椅子拉开。

“坐。我泡了一壶，喝不喝随你。”她坐回去，拿起第一个袋子，“从老的说起吧。”

“陆承。来了一年多，其实早就不用来了，他自己也清楚。还来，是因为班上有一个人。”她把袋子放下，“留不留他，你得先想好留他图什么。”

第二个袋子厚一些，她拿在手里没急着放：“顾宁。我最担心的是她。网上有个从没见过面的男人管了她两个月，手里有她的照片，知道她在哪个学校上课。她自己知道这样不行，就是停不下来。课上她说得少，说也是绕着说，我对她还没摸透。”

“苏曼和周慕白。”最后两个袋子她并在一起推过来，说到这儿笑了一下，“一个想要的，正好是另一个想给的，课上两个人已经对上眼了。苏曼规矩讲得比谁都清楚，就看她自己守不守；周慕白什么都说‘可以’，自己都不知道该在哪儿喊停。要谈的话，得替他把这个问出来。”

她给你的杯子添了点茶：“就这些。你有想细问的，随时来找我。”

门外，许棠探进半个身子，压着声音：“那个女的来了，早到半个钟头。我先领她去接待室坐着。”她又补一句，“对了，周日交房租，还有我们俩的工资。账上的钱撑不了几周，我就提一句。”

她看着你：“现在请她进来，还是让她先等等？”
