# 总结记忆包

记忆包用于保存或转移当前聊天的总结内容，不是聊天记录或完整回滚历史的备份。打开目标聊天，在剧情总结工作区的「数据管理 → 导入与导出」中操作。

## 导出与导入

- 导出下载 JSON 文件，包含关键词、事件、主要人物、角色别名、角色弧光和持续事实；不携带原聊天的楼层归属、逐楼锚点、向量或维护撤销历史。
- 导入先选择文件，再确认覆盖。它替换当前聊天的总结资料，清空当前聊天的锚点和向量，不删除聊天记录。没有总结的聊天也可以导入。
- 导入以目标聊天的当前末楼建立新的总结基线，不恢复原聊天的维护进度，也不能回退到被覆盖的总结。需要保留原总结时，先导出原记忆包。
- 导入完成后，可在记忆检索中重新生成锚点和向量。向量文件有独立的[来源验证与导入规则](./vector-cache-packages.md)，不与记忆包混用。

## 保存与失败

文件选择与确认绑定当时的聊天身份；确认、排队或读文件期间切换聊天，不得写入另一个聊天。取消选择或确认不提交导入；文件无法读取、格式不符或总结／向量任务仍在运行时，原记忆不被替换。

文件格式由 [summary-import.js](../data/summary-import.js) 定义并在导入入口校验，不接受任意 JSON。实际替换通过现有总结保存确认边界提交，只有确认保存后才报告成功；失败或保存结果待确认遵循[保存与生命周期](./recall-reuse.md#保存与生命周期)。
