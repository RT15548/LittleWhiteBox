# 同轮记忆复用验收

2026-09-16；SillyTavern 1.18.0，隔离数据目录，Chromium。

## 边界

总结模块持有一份已提交记忆，来源可以是 USER 或 AI。缓存只活在当前页面；无新配置、消息字段、持久化或保存请求。准备和提交沿用原有召回协调器，缓存命中发生在分词预热、数据库读取和召回之前。

正常生成产生新来源时替换缓存。当前回复的续写、swipe、原生重生成复用正文、角色与原边界，深度由当前聊天楼数重新计算。首次无缓存续写绑定实际参与查询的 AI；之后普通回复该 AI 会开始新的回合。quiet 和 impersonate 不消费或替换此缓存。

显式正文编辑、来源删除或替换、较早历史 swipe、手动总结变更、相关配置变化、切聊、禁用与缓存清理使缓存失效。删除当前回复保留来源时可复用。后台总结、补向量及普通隐藏开关保留本轮缓存；保留可见楼数影响证据装配，因此修改该配置会失效。

## 真实宿主链路

使用真实 `Generate`、宿主生成拦截器及存储事件。嵌入、重排和正文接口由浏览器路由返回固定结果；没有调用外部模型。这里验证请求次数和事件顺序，不以模拟接口耗时推断用户设备性能。

| 场景 | 结果 |
| --- | --- |
| 普通发送后，连续两次续写、swipe、流式重生成、再续写 | 只有首次召回；5 次复用未增加嵌入/重排请求，注入正文相同 |
| 新 USER 入楼 | 新增一次召回 |
| 单聊原生重生成 | 宿主先发 AFTER_COMMANDS，再删旧回复并发 MESSAGE_DELETED，随后拦截器复用；没有再次跳过前一条 AI |
| 后台改总结及向量边界，再令边界表读取抛错 | 仍复用原正文、原边界；当前 5 楼的注入深度按楼数重算为 4 |
| 连续执行 12 次复用拦截 | 嵌入、重排、聊天保存请求均新增 0 次 |
| 显式编辑来源正文 | 下一次重新召回 |
| 无 USER，首次就是流式续写 | 首次召回，后续续写复用；已采用记忆不因正文停止而丢弃 |
| 正常空装配结果 | 保留一份空结果，后续续写没有重复召回 |
| 两人群聊，流式及非流式 | 两个普通成员回复分别召回；末尾续写复用；整轮重生成删掉缓存来源后重新召回 |
| DICE 群聊连续鉴定，流式及非流式 | 5 次正文请求：normal → continue → continue → normal → continue。只召回 2 次，产生 4 次嵌入、2 次重排；三个续写均复用对应正文 |
| F5 后重新打开同一群聊 | 缓存数量 0；首次续写重新召回，第二次复用 |
| 停止未完成召回 | 缓存数量 0；下一次重新召回 |
| 停止后快速切聊，放行旧嵌入请求 | 旧请求未替换新聊天已经采用的缓存 |
| 真实总结面板消息入口 | 隐藏关闭保留缓存；角色配置、手动编辑事件、导入、清空总结均使缓存失效 |
| 手动总结保存期间点击停止 | 保存成功后缓存数量为 0；下一次真实续写重新装配并包含新保存的事实，再下一次续写复用这份新正文 |

缓存统计始终为 0 或 1；完成后检索运行时 `activeSessions=0`，没有向量或候选池留在复用槽。单聊每次续写/swipe/重生成只有宿主原本的一次回答保存。

浏览器测试脚本位于本地忽略目录 `output/playwright/recall-reuse/`；正式维护的稳定契约测试位于 `tests/recall-reuse.test.js` 和 `tests/recall-diagnostics.test.js`。

## Review 修复复验

手动总结的缓存失效现在先于取消检查执行，但仍要求原聊天及原执行身份匹配。成功保存后停止收尾，不再留下更新前的缓存。

- `manual-commit.cli.js` 使用真实总结面板消息入口，暂挂宿主保存请求，再点击停止、放行保存，并执行两次真实续写；验证上表新增场景。模型返回值为固定测试数据。
- 另以生产手动入口、生成器和缓存模块做存储边界回放：正常保存清缓存并执行收尾；保存中停止清缓存但不执行收尾；切聊、同聊重载后的迟到回调均保留新缓存；保存失败回滚时保留旧缓存。
- 宿主会在保存期间阻止切聊，所以迟到回调的切聊／重载隔离使用边界回放验证，不记为浏览器切聊成功。
- 修复后重新通过 255 项行为测试、诊断／取消回放、运行时检查、修改文件 ESLint 和 `git diff --check`。
