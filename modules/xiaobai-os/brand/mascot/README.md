# 小白形象

**母版是会动的 3D 角色，不是静态大图。** `design.ts` 固定组成、比例、表情和配色；`model.ts` 用这些数据生成实体；`performance.ts` 固定站立、抱物跑动和沿通路行走的节奏。搬家与筑家场景只提供角色的位置、实际路径和要搬的物件；不要在游戏或其他 APP 中复制一套模型或动画。改小白的造型或动作，先改本目录，再回游戏里看真实运动画面。

`svg.ts` 是 3D 模型的简化正面投影；`portrait.svg`、`mark.svg` 是 `build.mjs` 自动生成的静态辅助图，用在容不下 WebGL 的小尺寸位置，不定义角色长相。桌面小标记不覆盖用户角色壁纸。

`reactions.ts` 拥有观察、紧张、开心和失落的非语言姿态，不改母版比例。反应结束恢复入场姿态，不累积位移与缩放。`performance.ts` 的路径行走根据筑家的真实通路逐段移动；阅读、倚靠、午睡、喝茶和观察的姿势每帧从锚点应用，不积累变形。关闭动态效果时直接呈现静态活动。游戏拥有房间用途、有限行程和书杯等道具，角色目录不拥有房屋规则或生活进度。

筑家施工装和搬家搬运装分别由各自游戏的 `outfit.ts` 定义。`outfit-model.ts` 将装扮挂到原角色上，沿用所属场景的资源回收和原有动作；`svg.ts` 从同一份定义生成大厅头像，不再单独手绘另一套服装。基础模型与 Shell 标记不受影响。装扮不保存用户状态；移除某套装扮时删除该游戏的定义、场景挂载和目录头像注册即可。

不变的识别点是奶白椭圆身体、两只直立圆耳、两颗深蓝灰小眼、浅粉腮红和蓝灰小脚。面部不加鼻子或嘴；跑动时先短暂停顿，再身体轻轻上下颠、略微侧身抱物件。纸箱是搬家场景的道具，不是身体的一部分。其他应用只有确有角色参与的场景才引用该模型或它的静态投影。

来源：本仓库的程序化角色设计，不含下载图片或外部模型。仓库来源不等于版权或商标清权；对外独占或注册前需另做相似形象及商标检索。

删除路径：撤除 Shell 标记、游戏卡片、搬家及筑家场景的角色引用，再删除本目录和 OS 构建中的资源一致性检查；无用户数据需迁移。
