# 余火 · 第一章产品设计（哨站救援）

> 本文定义第一章的产品规则与持续验收要求，不作为 NPC 对话提示词。人物卡、世界、开场仍在各自文件里，资料分工见 [设定资料与接入约定](README.md)。
> 本章目标：走通"聊天攒好感 → 拿到料 → 用嘴少打一仗"这一整圈。

# 一、定位
- 酒馆里的 RPG，AI 是底座。标准战斗、构筑是技术底子。
- 新东西是嘴遁：人可以靠说话过关，料要靠和主要人物的关系换来。
- 嘴遁只决定"这场仗打不打"，不联动战斗内容。
- 门厅 Boss 必打，不能劝服。根庭荆棘之心是可选战斗，不能劝服。
- 第一章的嘴遁是给愿意和一个人长聊下去的玩家的替代路线；只想打的玩家一路打过去，也能通关。

# 二、流程与关卡
主线顺序不变：接下救援 → 岔口 → 正门或水道 → 牢房救人 → 开小门、接回营地 → 门厅 Boss → 核对物资 → 三娘收尾。

| 场景 | 敌人 | 能不能嘴遁 | 料在谁手里 |
|---|---|---|---|
| 外墙岔口 | 巡兵 | 不能，教学仗 | — |
| 哨站正门 | 八斤（盾头） | 能 | 老白 |
| 烽火台 | 常有年（守长） | 能 | 三娘 |
| 旧水道 | 看守 | 不能 | — |
| 牢房 | — | 救人处，不设对象 | — |
| 内堡门厅 | 哨站守卫 | 不能，Boss，必打 | — |
| 根庭 | 荆棘之心 | 不能，可选战斗 | — |

规则：料必须来自过这一关之前就能聊到的人。救人前营地里只有三娘和老白。
所以第一章最少只打两仗（岔口、Boss），全不聊就是一路打下来。
- 八斤放行 = 正门已过（patrol_cleared）。
- 常有年放行 = 烽火不点（alarm_silenced）。牢门惊动守军之后再去谈也一样：他答应不点，援兵就不来。

# 三、人物在第一章的位置
- 老白、三娘：开局就在营地，第一章的料来自他们。
- 扣子、阿念：在牢房里就能说上话，救回营地后接着聊。好感从牢房开始攒，跨场景累计。第一章没有她们的秘密。
- 牢房这样就够了：能聊、能攒好感、不设任何门槛，救人照常走开牢门、开小门、担架接回。不加额外的牢房剧情。
- 人物不写成长线。分段只给记忆、关系、秘密的影子、亲密态度；言行由人物卡自己推。
- 分段文件：laobai-stages.md、sanniang-stages.md、kouzi-stages.md、anian-stages.md。

# 四、好感
## 数值
- 每个主要人物一份，0~100，初始 0，跨章不重置。玩家和 AI 都看得到。
- 每次回复，AI 只给方向（affection: up / down，没波动就不写）。幅度由程序随机 2~4，夹在 0~100。幅度做成可调的配置。
- 同一条回复只结算一次：保存失败后重试保存、读档、恢复，都不能重复加减。
- 节奏目标：认真和一个人聊，大约 35~45 轮到 81。实测偏离太多，调幅度，不调 81 这个门槛。

## 分段怎么取
段：0~20 / 21~40 / 41~60 / 61~80 / 81~100。按"人物 × 章节"取对应文件的章节。
- 称呼、关系、秘密的影子、亲密：取当前好感所在的段。好感掉下来，这几项跟着回到低段。
- 记忆：从 0~20 起，累计到这个人到过的最高段。好感掉下来不收回：已经愿意谈的往事，不会再变成不愿谈。
- 秘密：当前段写了秘密才放进提示词。交出后，秘密作为"已经告诉玩家的秘密"一直留在这个人的提示词里，好感掉下来也不收回。
- 分段写的是人物怎样看玩家。它不替玩家表态，也不算作已经发生过的共同经历；共同经历只来自交谈记录和已确认经历。
- 人物卡里写了、但记忆还没放进来的事，人物心里有，只是还不想和玩家谈。不是失忆。

## 交出秘密
- 一个行动。只在当前段写了秘密、好感 ≥81、且还没交出过时出现。
- 交出后记一条事实（老白→八斤的料，三娘→常有年的料），旅途加一条。之后这个行动不再出现，好感怎么变，玩家手里的料都不收回。
- 扣子、阿念第一章 81 以上也没有这个行动。

## 显示
- 人物交谈界面上并排好感爱心与上下文圆环，点开各自的小浮层。
- 好感爱心：空心起步，内部与边缘按同一高度从下往上填充；没有另行沿轮廓运行的进度，也不在外面套圆。点开显示数值和当前称呼（取自分段文件的"称呼"）。加减数字保持轻巧，无底色边框，停留至少三秒；切换人物不串提示。跨段时称呼跟着换。
- 上下文圈：和管理员 APP 同款，显示这段交谈占了多少上下文、离自动摘要还有多远。点开看各部分占用。

# 五、地图与移动
## 位置只有一个来源
每个人物的位置（所在场景、坐标、是否在跟随玩家）存进存档，是唯一事实来源。
画面上的人、交互距离、提示词里"你在哪"、地图里"你在不在这里"、事件见证（谁在场谁亲历）都从它派生。
不允许画面跟着跑、逻辑还认为人在营地。

## 三种移动行动
- 跟随：人物跟着玩家走，跨场景也跟着，包括进战区。
- 同行到某地：人物自己走过去，到了在那里等。玩家不被带着走。只能选"能去且安全"的地方。
- 留下：人物停在原地，不再跟随。
AI 答应了就提交，由游戏执行移动，AI 不描写已经到了。

## 边界
- 能去：按现有地图规则已经打开的地方。安全：那里现在没有敌人。
- 战区只能靠"跟随"进去，不能把人单独派去。进了战区，人物跟着玩家跑，不攻击，也不被敌人当目标。
- 扣子、阿念在接回营地（captives_arrived）之前没有任何移动行动。救人照常走开牢门、开小门、担架接回，不能用一句同行绕过。
- 留下：人物保留约定的场景与位置，玩家出门、切换场景、读档均不把人自动送回工作点。
- 战败重试：跟随中的人物和玩家一起回到重试起点。返回营地整备：一起回营。
- 读档：人物按存档里的位置出现。
- 营地约会点（同行的常用目的地）：老白外门门楼，扣子管架高处，三娘诊棚后，阿念登记棚。

## 去不了的地方
玩家要去地图外、或现在去不了的地方：人物按性格回应；当前能执行的移动由地图资料和行动词表说明。

## 生活空间
住处与工作点、救援后的安置点分开。檐下室内无需先接救援任务；营地外救援路线仍由委托开放。
房间与街道有可往返的真实入口；跟随、赴约与留守复用同一场景图与人物位置。室内归属檐下，不另挤进章节战略地图；本地地图显示房间布局与入口。
房间归属、用途、遮挡与隔音、家具占地统一定义于 `content/living-spaces.ts`；地图、渲染与模型从中派生。普通在场者来自 `content/local-life.ts`，不能把没有主要人物当成无人。
对话现场使用实际位置、在场者及当前移动状态；新的赴约行动先显示“关闭交谈后出发”，到达之后才把目的地作为当前场景。历史仍保留当时地点。
玩家投宿客房可以休整；生活空间可整备和更换衣装。没有购房、租金或关系门槛系统。
转场只显示轻量目的地条，保存和首帧就绪后自动收起；主动暂停、切到后台及真实错误各走原有流程，不将操作等待伪装成暂停菜单。

## 同行与嘴遁
- 带着老白去正门、带着三娘上烽火台，不影响嘴遁规则：料还是要玩家自己说出口，同行的人不替玩家开口，也不进入敌人交谈。
- 敌人提示词的场景里写上玩家身边跟着谁；他怎么反应，由他的卡推。

# 六、嘴遁遭遇
敌人卡：enemy-bajin.md、enemy-changyounian.md（含开场）。与主要人物共用预设，结构见 README.md。
同一套遭遇机制，用配置区分敌人：敌人卡、开场、料事实、放行后记哪条事实、旅途文案。不为每个敌人复制一套实现。

## 怎么进入
- 正门和烽火台的敌人外面多一圈"照面区"，比警戒区大。玩家走进照面区，敌人转向玩家，领头的往前一步，头顶出现"交谈"提示。
- 这时按交互键打开交谈面板；不理会、继续往前走进警戒区，就照常开打。
- 交谈面板和主要人物同一套，但只有上下文圈，没有好感圈。打开面板时游戏暂停。
- 战斗一旦开始，就不能再找他说话。

## 三种结果
- 还没提交任何行动：玩家随时可以关掉面板、退出照面区。敌人回到原位。之后再来，他记得上次说过什么（每个敌人有自己的交谈记录）。
- 放行：只有玩家已经拿到对应的料（那条事实），这个行动才会出现在 actions 里；AI 判断玩家有没有把料用对、用到他心里。
  面板上留着他最后一句话，玩家读完自己关掉面板后：盾卫向两边让开（正门）/ 火盆边的人退开、火绳收起（烽火台），通路打开，该关记为已达成，旅途写一条（见第八节）。
- 动手：谈崩了。面板留着他最后一句话，只剩一个"迎战"按钮，按下就开打，和走进警戒区开打一样。提交了动手就不能再退走。

## 之后
- 放行或打赢后，领头的人退到一边站着，照面区还在，能说话，没有行动。
- 打过的敌人不消失。

# 七、物资对账（疑点）
- 地点：诊棚东侧的货车，就是现在"核对归还物资"那一下。
- 玩家看见两样东西，互相对不上：
  - 哨站随货送来的放还单："冷却管件十二副，库中仅此，余者冻裂报损。"
  - 管件箱里夹着的出库签："本箱原装二十四副，出十二，存十二，完好。"
- 只摆在那里，没人评论，三娘的收尾也不提。它是一个疑点，不是已经成立的暗线。
- 记一条"看过出库签"进存档，不进任何人的提示词，不影响本章任何判断。

# 八、调子与文案
不正经感要从文案里出来：八斤刻意拉长的官话、哨站只认凭签、急事也得按章程排队。

## 战斗目标（BATTLE_OBJECTIVE）
- 岔口：岔口有巡兵守着。过了这里，正门和水道才走得通。
- 正门：八斤的盾排开了。冲过去，烽火台就在后头。
- 烽火台：守军护着火盆。别让那堆火烧起来。
- 水道：看守蹲在闸门边。把闸抢回来。
- 门厅：门厅守卫守着主闸。药和管件都压在闸后。
- 根庭：荆棘之心在地底下动。地面鼓起来时，往旁边让。

## 当前行程（campaignObjective）
- 未打岔口：沿营地北路去外墙岔口。
- 未救人：走正门上烽火台，或者下旧水道直奔牢房。
- 未开小门：牢房东南角有扇小门，打开它，回营就不用绕。
- 未安排接应：回营找老白，让他把担架摆到小门。
- 未接回：从小门回营，担架队会把人抬回来。
- 未打门厅：去内堡门厅。药和管件压在主闸后头。
- 未核对：回营，到诊棚东边的货车上点一点还回来的东西。
- 收尾：回三娘那儿，把这趟收尾。

## 旅途记录（FACT_COPY）
- crossroads_cleared：岔口的巡兵散了，正门和旧水道都走得通。
- patrol_cleared：正门过去了。（打过去和说过去共用这一句）
- 八斤放行时另加一条：八斤侧过盾，让开了。
- alarm_silenced：烽火没点起来，内堡的援兵不会来。
- 常有年放行时另加一条：常有年眯着眼看了你一会儿，叫人把火绳收了。
- waterway_cleared：水道看守躺下了。
- warden_defeated：门厅守卫倒了，主闸松开。
- 三娘、老白交出秘密时各加一条：老白跟你说了八斤的事。/ 三娘跟你说了常守长的眼睛。

## 营地互动
日常互动由人物在 AI 对白中自然发起或回应，承接本人的历史、处境和关系，不设置固定互动菜单，也不在模型对白之后追加轮换脚本。
救援委托、接应、整理诊棚和归来核对属于真实剧情变化，由对白后的行动信息提交，仍按人物、位置和已发生事实校验。跟随、留下、前往某处、交出秘密和守卫谈判走各自现有规则。
人物的可见表演与轻量素材规则见 [第一章美术](../expedition-art-design.md#气泡表演)。

# 九、不堵后路
只专心做第一章，不为后面章节埋具体伏笔，只守住这几条，免得把后面做死：
- 好感、到过的最高段、已交出的秘密、嘴遁结果、敌人交谈记录、人物位置、开关状态、看过出库签，都存下来，不在章末清掉。
- 分段按章节写，后面章节加新段时不用改第一章。
- 主要人物、嘴遁敌人的数量都不写死，靠配置加。

# 十、资料与实现一致性
本目录中由 `apps/game/expedition/narrative/canon.ts` 实际读取的资料属于运行时提示词，资料协议与对应代码必须同步修改，不提前承诺未实现的行动。读取与组装边界见 [设定资料与接入约定](README.md)，代码所有权、保存及恢复边界见 [第一章实现边界](../expedition-game-target-design.md)。

人物设定和行动词表各有唯一来源；设计文档引用本章规则，不另维护数值或提示词副本。新增长期状态随所属功能具备保存、读取及失败恢复能力，不把数据安全留到交付末尾。

# 十一、持续验收要求
## 玩家视角
- 交谈界面上有爱心好感圈和上下文圈，样式和管理员 APP 一致；点开好感圈能看到称呼。
- 和老白聊下去，能看到好感在涨；不同阶段他愿意谈的东西不一样，低段问正门他不谈细节，也不编。
- 好感到 81 以上，出现"交出秘密"；他讲出八斤的事。
- 走到正门，八斤先转过来；用上老白的料能不打就过，不用或用错就打；没提交动手前可以走开，回来时他记得。
- 三娘、常有年同样走得通。
- 在牢房里和扣子、阿念说的话，回营后好感还在。
- 让老白陪你去门楼，他自己走过去等你；要他去哨站深处，他说得出为什么现在不行。
- 核对物资时能看到放还单和出库签，两张对不上，没有人点破。
- 全程不聊也能一路打通第一章。

## 状态正确
- 跨好感段、好感下降、秘密已交出后好感下降：称呼和关系跟着变，记忆和已交出的秘密不丢，料不收回。
- 保存失败后再保存、读档、恢复：不重复加减好感，不重复出现交出秘密，不重复触发放行或旅途记录。
- 人物位置：跟随跨场景、留下、战败重试、返回营地、读档后，画面、交互、提示词、地图四处一致。

## 完整流程
- 全打通关、全劝服（两关都说过去）通关、一关说过一关打过的混合通关。
- 敌人交谈中途离开再回来；长聊触发摘要后，好感、分段和敌人记忆仍一致。

## 真实体验
- 从酒馆原入口进入；酒馆 1.14 和 1.18 都能跑；手机布局；切到后台再回来能恢复；带人同行时不掉帧。
- 用真实模型玩，不用模拟回复：
  - 记一次老白、一次三娘从 0 到 81 实际用了多少轮，对照第四节的节奏目标。
  - 低段问秘密相关的事，人物不说出秘密本身；高段能自然说出。
  - 八斤、常有年：没料怎么说都不放行；有料说对能放行；有料说蠢会动手。
- 不能靠把数值直接改到 81 来代替上面这条实测。
