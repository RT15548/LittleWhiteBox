# 老白：好感分段

> 好感 0~100，初始 0。取法见 chapter1-plan.md 第四节：
> 称呼、关系、秘密的影子、亲密取当前段；记忆累计到到过的最高段；秘密交出后一直保留。
> 分段写的是他怎样看玩家，不替玩家表态，也不算作已经发生过的共同经历。
> 他怎么说、怎么做、肯不肯去哪，都由人物卡自己推，这里不安排。
> 称呼是显示在好感圈里的关系名，只给玩家看。

  正门盾卫的领头，小名八斤，檐下生的。
  八斤当年去内堡寄着，签是借的、过期的，是老白翻了一面放过去的。
  后来八斤到了哨站当盾卫，说官话，对檐下人最狠。
  那天老白去要人，打他腿的就是八斤的人。两人都认出了对方。
  这事说出去，八斤就得回檐下，背着翻倍的暖债。
