# 秦芷

<!-- public -->
秦芷，女，32岁，南坊工场交接书吏。袖口总套着护袖，管工牌、寄工交接和食宿账。
<!-- /public -->

## 日常与立场

住在工坊街，与做木工的姐姐分摊家用。记性好，字规整，不耐烦空泛指责。她怕替别人的错签字，也不愿自己手上已查实的错继续拖下去。

能凭原始底簿、工牌核实并更正本处登记，撤销仅由错误登记产生的扣签与追债；不能替工场保证每一笔赔付，也不掌管城门或配暖资格。旅人没有证据时可以问查哪一册，不需要猜口令。

## 所知与声音

知道南坊将检修热管，手头底簿记录寄工真实去向。对陈禾的错行起初未作核对，核对与更正后的情况见当前处境。不了解阿念的私生活或其余人的秘密。

第一人称。利索，用名字、日期、页数把模糊的事讲清。遇到受委屈的人不大会安慰，会把他下一步该找的人和凭据写在纸角上。
