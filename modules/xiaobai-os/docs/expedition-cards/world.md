# 余火：世界

# 立意
一座炉在变冷的城。暖是稀缺品，暖按名分发，名由内堡记。
没有名的人活在墙外，等一个永远不会来的核定。
调子：官僚荒诞加民间。人人都在按规矩办事，规矩合起来把人逼到绝处，说出来又有点好笑。

# 一、世界规则

## 1. 地理
赤炉城:
  中间是古炉，炉渐冷。炉外是旧城墙，墙内叫内堡，墙外自搭的一片叫檐下。
内堡: 在册者的住处。有官署、铜管司、炭库、药库。
檐下:
  官名"第七待核区"，檐下人自己叫檐下。待核是永久状态。
  自己搭的棚屋沿着管线和墙根长，暖气靠从内堡漏出来的管线。
哨站: 内堡一侧，设在外墙。只验签，不管人，扣押人和往来的货物。
外门: 檐下通往内堡的门，在哨站之前，由檐下自己安排人看守。
旧庭: 外墙下的旧院子，荆棘长在漏热处。檐下的诊棚在它边上。
旧水道: 外墙到牢房那一段，众人皆知，可以绕到牢房。

### 城外
赤炉城坐落在北方山地与河谷相接处，是这一带的炉业、医药和转运中心。古炉供暖的是这座城及相连管线，不是整个世界。
城外有耕作的河谷村镇、林场、炭窑与采石聚落。山地寒冷，河谷能种粮；更南方有温和的平原、通航的河流与别的城邦。世界远不止赤炉城，各地也不都靠古炉过活。
粮、盐、布和木炭经河谷驿路送来，矿料与药草从山路下城；赤炉城向外卖炉件、铁器与加工药品。近处村镇通常走一两天，较远的城要随商队走数周，遇上雪封山口还要等路。
离城要备口粮、燃料、路费和落脚处。檐下有人替商队扛包，有人在城外有亲戚；欠下的暖债、城里的家人和外地无着落的生计，让搬走不等于脱困。内堡的名分在本城管用，外地各有自己的章程。
檐下人熟悉附近驿路与赶集去处，远方的事多从商贩、脚夫和旅人口中听来；传闻会互相矛盾。古炉为什么日渐冷下去，尚无公认的答案。

### 檐下的日常
人家挤着管线搭房，街边的炉子几户合用。有人补衣、有人守锅，热水要提着桶送；诊棚檐下晾的是洗净的布，药材挂在避雨处。柴头、旧铜箍、磨薄的碗都还有用处。
清早是烧水、送货和排诊的时候，赶路的人从做活的人身边穿过去。炉冷、缺药也挡不住讨价还价、串门和拿熟人打趣，檐下不是只有等着被救的人。

## 2. 名分
- 内堡在册，檐下待核。待核需要一个在册者作保，核定才算数。
- 作保要用自己的暖担着，没人愿意，所以没有一个待核者被核定过。
- 名由内堡记。檐下人的名字在内堡的册子里没有位置，檐下自己有一套登记，不作数。
- 在册女人的户籍只记"某氏几女"，户主写男人。
- 檐下女孩走进内堡的唯一后门是嫁进在册户。
- 在册的人叫户名，檐下的人叫小名、外号，谁叫谁认。

## 3. 暖
- 暖是一切：炭、药、热水、油，都算暖。炉冷了，暖不够，就按名分发。
- 暖要用"签"领。签按人头发，有期限，过期不认。
- 哨站只认签，不认人。签对，药摆在眼前也给；签过期，人快死了也不给。
- 要多领一份，就要多一份签。多的签从在册的亲戚手里匀，欠一个人情。
- 暖债：领了暖，没钱付，就欠着。
- 寄着：到内堡做工抵暖债。男的进炉膛，女的进内堡（洗衣、抄写、厨房）。
  工钱永远比暖费低，债越寄越多。
- 点灯官：炉冷了，由点灯官担责。这个官职没人想当。
- 《闸约》：内堡与檐下的旧约。檐下不得有军队，不得有武备。
  条文上，担架队是医护人员，不算武备。内堡不得在檐下驻兵。
- 荆棘：长在漏热的地方。清理它得花暖，所以没人真想清，只是说要清。

## 4. 魔法
魔法已经退潮。碎晶是登记在册的公共物，不是谁都能用。
第一章的四个人物都不会施法。内堡医术所用的碎晶是工具，檐下没有这种条件，只剩针、刀、草药。
过去使用碎晶的经历可以谈起，不代表眼下具有施法能力。
城中的居民都是人类。

## 5. 衣着
衣着主要参考民国时期的市井与工矿衣装，结合炉城御寒、行医和劳作的需要。交领、立领、系带与扣襟并存，也有短工装、长外套、裙装和耐磨裤。
檐下常穿棉麻、旧呢与补过的衣物；内堡的面料更细，裁剪与扣饰更讲究。贴身多用柔软棉布，鞋袜随天气、家境和工作而异。衣物会随生活与旅途更换。

## 6. 语言
- 内堡说官话，檐下说土话。
- 官话越长，事越办不成。内堡人说话先铺垫，再三层客气，最后什么也没答应。
- 檐下土话短，动词多，不绕弯。听到官话，先假设对方在糊弄。
- 常用词：耐烧（靠得住）、费炭（花费大、不划算）、还没灭（还活着、还撑着）、
  寄着（寄身做工）、留着火（保住自己的暖，给自己留退路）。
- 骂人的话也带暖：浑身上下扣不出半钱碎晶。

## 7. 起名
- 檐下的名字有来历：
  女孩的小名是爹娘的盼头（盼门、进喜），男孩按斤两排行（六斤）。
  成年后会得到一个外号，外号比小名好用（扣子、门闩）。
- 户籍名只有在册者有。待核者没有户籍名。
- 在册女人嫁人后户籍名不用，只记"某氏几女"。
