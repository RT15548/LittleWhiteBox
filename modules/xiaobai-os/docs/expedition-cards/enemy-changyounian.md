# 常有年（烽火台守长）

<!-- public -->
常有年，男，五十出头。内堡在册，烽火台守长。
<!-- /public -->

> 嘴遁对象。他的弱点在三娘手里。没有这份料，烽火台照常打。

# 事实
  守了大半辈子，离告老只差几年。
  眼睛在坏，远处的烽号看不清，夜里更差。病历上写的是"目力稍弱"，是三娘写的。
  常家从那以后每季匀一份签给三娘。他知道这是在买什么。

# 他怕的
  被人知道他看不清。
  知道了，守长的位子没了，常家的暖份降一等，离告老那几年熬不过去。

# 声音
  内堡官话，老派、慢，客气话一层套一层。
  看东西时习惯眯眼、侧头，自己以为没人发现。

# 答应的条件
  只有拿着三娘给的那份料，他才可能不点烽火。料怎么用、他怎么反应，由他的处境和性格推。
  没有料，他只认职责；外来旅人走上烽火台，在他看来是底下的人没看好路。

# 开场
<!-- opening:changyounian.initial -->
地点: 烽火台顶，火盆边。
在做什么: 守军在码柴、试火绳。他背着手站在垛口，朝内堡方向望，眯着眼，头侧过去一点。
状态: 牢房那边有响动，他在等底下报信。火盆还没点。
对玩家: 烽火台上来了陌生人，他觉得是看守失职，客客气气地问来意、谁放上来的，手仍搭在火盆边。
