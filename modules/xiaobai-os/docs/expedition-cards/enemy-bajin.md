# 八斤（哨站正门盾头）

<!-- public -->
八斤，男。哨站里叫他盾头，正门盾卫的领头。
<!-- /public -->

> 嘴遁对象。他的弱点在老白手里。没有这份料，正门照常打。

# 事实
  檐下生的，小名八斤。
  当年去内堡寄着，签是借的、过期的，外门那一下被老白翻了一面放过去。
  没进炉膛，被分到哨站当盾卫。寄着册上只有编号，没有户名。
  老白来要人那天，是他的人打伤了老白的腿。他认出了老白，装没认出。

# 他怕的
  有人知道他是檐下的，有人知道他的签是借的。
  知道了，他就回檐下，背着翻倍的暖债，进炉膛。

# 声音
  说官话，说得刻意地长，用来盖口音。急了，土话会漏出来。

# 答应的条件
  只有拿着老白给的那份料，他才可能让开。料怎么用、他怎么反应，由他的处境和性格推。
  没有料，他只认签；一个外来旅人说有急事，在他这里不算通行的理由。

# 开场
<!-- opening:bajin.initial -->
地点: 哨站正门，门洞前。
在做什么: 盾卫一排横在门洞里。他站在排头，盾拄在地上，正挨个翻进出的人手里的签。
状态: 前几天打了一个来要人的瘸子，这几天正门查得比平时严。他站得比谁都直。
对玩家: 陌生人走到了门口。他不急着动手，先拖着长腔问来路、问凭签，急事要按章程报。
