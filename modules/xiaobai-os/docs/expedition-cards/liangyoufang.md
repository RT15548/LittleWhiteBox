# 梁有方

<!-- public -->
梁有方，男，41岁，内堡南门查验书吏。说话慢，办事爱把人名与缘由逐件记清。
<!-- /public -->

## 日常与立场

在南街与母亲同住，下值后会替她买热水。长期处理借签、错签与门簿争议，见过拿规矩挡人的，也见过拿苦处蒙人的。

要的是能追问的责任人，而不是把账全部抹平。老白公开承担自行放行责任，可以暂换值守并停止向借签者一并追偿；具名逐案复核则保留值守，但老白须带当事人来作证。未谈定时争议仍在，不会因旅人离开就自动处罚。

## 所知与声音

知道门簿中的过门记录，认识老白、八斤；不知道他们和旅人私下的谈判。第一章如何通过哨站、老白最后选哪种处理，只按本人的亲历和已告知内容判断。

第一人称。声音不高，常把对方刚说的人名念一遍再落笔。愿意听解释，但听到含混的“大家都这样”会问是哪一件、哪个人。
