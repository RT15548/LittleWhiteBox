# Map 场景绘制设计

## 事实与表现

Map 分区是唯一地图事实来源，二维 SVG 与三维 Three.js 读取同一份场景。工具和领域拥有位置、占地、朝向、材质 token、确定性与对象语义；渲染器不补门、挪家具、添人物或修改事实。

空间合同见 [Map 产品设计](./map-app-target-design.md)，词表归 `domains/map/semantics.ts`，资产映射和支持比例归 `scene3d-asset-catalog.ts`。来源、转换与许可证见 [Kenney 资源说明](../apps/map/ui/three/assets/kenney/SOURCES.md)，不在文档复制物件或资源枚举。

默认打开当前 active 场景的三维视图，没有当前场景则显示二维世界地图。可切二维；WebGL2 不可用或整体图形故障时明确回退二维。这是浏览器兼容能力，不是旧模型分支。

## 环境光

`scene-lighting.ts` 拥有自然光配方、局部灯源位置和预算，APP 与聊天投影共用。灯位来自已有灯具、火源或光照区域的几何，灯色来自材质；人工照明开启但没有灯位时，以主地面上方的宽范围照明表现，不新增可见灯具或持久化位置。环境字段不改变画布背景。

三维 `scene3d-lighting.ts` 拥有半球光、太阳方向光和有距离衰减的局部点光源；受光、遮挡和阴影发生在地面、墙壁、家具上。自发光灯罩不遮挡自身光源。局部光源和阴影数量受共享预算限制，移除或卸载时立即释放灯源及阴影贴图，继续按需绘制，无常驻动画或定时器。二维保留俯视示意，用相同灯位与范围在地图图形上混合局部受光，阳光为物件产生方向性投影；二维不模拟三维遮挡。

自然光不足仍保留最低示意照明，人物、入口、名称和操作控件不随环境一起变暗。光照更新保留几何与当前视角；缺省契约及保存语义见产品设计。维护时建图正常填写光照，已有场景随日光和灯光变化更新。

## 二维空间

- 墙和开放路径只表示边界，不填内部、不补入口；closed 取领域规则，不按名称猜闭合。
- 已知尺寸物件画原占地与俯视细节；陌生物件保留轮廓、材质和名称。icon/label 仍是点标记，不猜体积。
- rotation 按领域中心顺时针应用，文字不随物件旋转。普通更新不重置视口。
- 纹理、木纹、阴影、线宽和林地装饰由本地绘制派生，不作为工具参数或存档；装饰有稳定种子、裁剪与固定预算。
- 默认不铺工程网格，显式网格仍显示。开放线标签贴近路径，不取包围盒中心；人物和入口保留标记。
- 二维图标与字体失败时的文字表示不导入 three 或模型加载器，能独立构建。

## 三维造型与适配

表示顺序：位置标记 → 路径设施 → 形状／比例匹配的本地模型 → 合格程序造型 → 原占地示意。单模型失败不改 certainty 或存档，不拖垮场景。

模型为 Y 向上、底面零、占地中心原点，二维映射到 XZ 平面。旋转仍按二维合同，家具背面、桥向和物件正面由资产适配约定定义，不新增坐标体系。

等比适配优先。可伸缩台面／横梁用程序分段，腿、轮子和圆孔保持比例；树冠、旗面、扶手也受占地约束。不能适配时回到可用表示，不越界、偏移或任意压扁；不规则轮廓不硬套包围盒。

程序形体与本地模型统一测量水平范围；未贴合时补原始地面轮廓，贴合则不加框。细人物、入口和尺寸物件切换不消失。显示高度是风格化约定，不用于建筑测量、层高推断或物理模拟。

### 自然形体与生物

物件和材质仍使用原有 `icon` / `material` 字段，词表和工具分组从领域定义派生，不新增必填字段、三维存档或美术生成步骤。旧文档直接有效；显示不触发地图维护、不回填材质、不按名称猜生物类型。旧图直接获得共用材质、接触阴影、林地和边线改善；专门造型需要已有或后续显式提供的类型信息，不自动改写历史地图。

`scene-forms.ts` 是二维／三维共享的形态适用条件与缺省表面来源。开放生长体／管线沿原有路径构造有体积的截面，粗细、渐细、叶片和吸盘属于有预算的表现细节，不是新增实体或真实占地。闭合轮廓不猜成中心线。静态生物与自然结晶按矩形／圆形占地等比适配；圆形用实际顶点半径约束，不能只约束包围盒。

有明确尺寸且有合格造型的角色可以显示静态棋子，角色身份仍由 `actorKey` 所有。真实位置锚点保持在地面；标记从形体上方排布，引线仍连接真实位置。只有点位置的角色继续显示本地图形符号，不猜体型。二维与三维共用本地矢量符号，字体失败也能辨别新类型。静态造型按表面合并部件，同场景复用只读原型；无骨骼、常驻动画、远程素材服务或新依赖。

### 表面与视觉层级

纹理由确定性程序生成；自然表面按材质组织粒度、脉络和纹理方向，不以同一套噪声换色代替材质区别。材质区分粗糙表面、金属与湿润表面，自发光仍遵守光照契约。三维使用低分辨率中性反射环境补充材质高光；它不显示虚构房间、不添加地图灯位，夜间降低反射贡献，卸载释放资源。接触阴影只放在实际尺寸物件内部并受预算限制；它不是可通行区域或额外占地。

地面配方由 `scene-ground-surfaces.ts` 所有，二维与三维共用确定性表面数据：沙纹、石质裂隙、土粒、草叶／落叶、雪面、大理石脉络、木板和瓷砖各有结构。颜色、凹凸和粗糙度独立生成；三维只对颜色通道做 sRGB 解码，凹凸不改变占地或生成可通行地形。纹理按场景展示尺度平铺，不随物件长宽拉伸。二维从同一数据生成局部图案，不引入 Three.js；地面配方不覆盖家具、生物或墙体的表面。

只生成当前视图用到的地面材质。二维图案由组件持有，三维贴图在场景内复用并随场景释放；不建立跨聊天缓存、磁盘纹理或远程资源请求。视觉验收同时检查实际地图与紧凑投影、灰度可辨性和不同光照，不以材料色值不同代替质感成立。

地面厚度向下生成，顶部和水平边界仍由原始几何确定。林地冠层与树干仍为原区域内的装饰，不代表逐棵树事实。占地边线保留但降低视觉权重，不确定性的虚线与透明度继续可辨；名称和角色标记保持独立的屏幕空间层级。材质、几何与标记优化同样用于 APP 和聊天投影。

材质与 certainty 在实例侧应用，不污染共享原型；未给材质不回填数据。素材附带的独立书本、餐具等去除，不创造地图事实。深色 UI 不把实体统一染暗，灯光行为与预算见环境光章节。

## 加载、视口与资源

只在进入三维时加载代码与当前场景可适配的 GLB。世界图和纯二维路径不下载模型。当前场景会话共享只读原型及请求，更新复用有效引用，退出释放，不建跨聊天持久缓存。

首次三维代码返回后，仅在组件仍挂载、宿主页可见且容器已接入页面并具有尺寸时创建 WebGL 上下文；隐藏期间等待尺寸或页面可见性通知，恢复后继续，不轮询、不设置猜测延时，卸载注销等待。

先画可用表示，同批所需资产全部完成或失败后统一通知替换，不因每种资产到达各自重建整图；失败项保留可用表示并报告。替换保留相机、低墙和名称选择。首次取景用发布模型尺寸预留高度，不等下载后重置；到达后更新锚点和灯光范围，不自动全图。屏幕标记按当前相机和画布投影，扩图或 viewBox 改变不移动事实位置。

场景按内容判等，不因状态快照换了对象引用重建。场景、主题和资产变化合并到可见绘制帧，隐藏或从楼层取下时不构造模型、不绘制；恢复后只应用最新状态。重建先释放旧模型再创建新模型，保留坐标框架与视角，避免同时持有两份完整实例。

更新／离开淘汰旧任务。能取消则取消，解析晚到时核验归属并释放；不能复活已删对象或卸载组件。单资产故障有诊断，不在同会话循环重试；整体故障清理后回退二维。

二维与三维保留视角，但不保留已中断的手势。手势期间观察所属指针的结束和捕获丢失，容器隐藏、页面转入后台或卸载时结束全部指针；取下 DOM 后在文档收到的松手也必须清理。三维通过不冒泡、不穿越 Shadow DOM 的本地取消输入结束 OrbitControls 状态，不触发宿主生成或消息事件。

资产会话拥有原型 geometry、texture、material 和解码图片；场景拥有实例、自建资源和程序造型原型，渲染实例拥有反射环境。先移除实例，再释放无引用原型，ImageBitmap 和对象 URL 一起清理。临时隐藏暂停绘制并保留当前实例；卸载和失败清理观察器、绘制及 GPU，不能靠垃圾回收代替。楼层投影的实例所有权与释放边界见 Map 产品设计。

## 分发与删除

只发布精选本地静态 GLB，纹理内嵌；无远程 URI、脚本、骨骼、动画、模型灯光／摄像机或额外解码依赖。每包原许可证保留，平台名称不等于再分发授权。

Vite library mode 使用显式不内联 URL，将模型输出为内容哈希资源；模型、JS、许可证成套发布，APP iframe 与宿主内投影均按模块 URL 解析资源。不能将整套 GLB 内联或要求运行时 Git LFS、远端服务。

删除三维表现层移除 three 目录、三维组件／入口及专属构建资产，保留二维和地图数据；整功能删除按 Map 数据策略清分区及注册。视角、会话与图形状态临时，无三维存档或迁移壳。

## 验证与限制

纯逻辑保护几何、朝向、闭合、占地、确定性与预算；边界检查合并加载、旧结果失效、资源释放及二维独立构建。正式组件检查多场景、视口、主题、放大、导航、触控、更新与故障，浏览零模型调用。旧数据同输入对比与新增语义对比分开；工具词表增长使用本地 tokenizer 度量，不能当作供应商实际费用或模型正确率。

手写 Tool 样例只证明编译／保存／读取后可呈现，不证明真实 Agent 首绘或增量质量。实体手机 GPU、连续旋转帧率和各 WebView 尚未完整验收，不把桌面视口模拟写成手机性能保证。
