# 余火终章：长夜重燃

本篇是终章产品设计，不注入模型。承接[墙里灯火](expedition-chapter2-design.md)，战斗遵循[统一战斗设计](expedition-combat-design.md)。世界基础、人物内核、关系尺度仍归各自设定源。章节用于制作编排，不出现选章入口。

## 玩家旅程

旅人已经救回受困者、修通檐下回流。目标从争取一支热源，推进到保住自己与这些人往后的生活；不重置关系，不撤销已经确认的婚籍、通路与登记结果。

1. 回到檐下，看见公共热水和生活恢复，收到炉城赴宴邀请。读完邀请才展开新行程，第二章胜利保持成立。
2. 在炉城高台俯瞰城内外。掌炉官裴肃给出点灯官的职位、住处与迁入凭证，要求旅人为续炉安排站台。可以离席，不以一句对白锁定结局。
3. 在分暖站了解替代方案，去雪线旧驿验证分炉。魔力退潮使大炉的旧运行方式难以维持；续炉集中晶材、缩小供暖范围，分炉则结合普通燃料、分区维护。第二章修通的回流是停炉改造的周转条件。
4. 在旧站清除泄热口的荆棘、实际试炉并装运炉件。沿雪谷运输道突破炉卫拦截，把设备带回城里。运输不使用脆皮货车血条。
5. 熟悉街区出现迁居准备；工班开始分炉改造。可实地争取物资、通路与人员协助。穿过炉下旧城，由运输平台或外侧检修架登炉，两路互为替代，不强制收集四位人物的许可。
6. 炉前整备、同行者相处后进入炉心。裴肃正在将可拆分晶材投入强烧，旅人必须夺下设备。战胜后亲手停止续炉，返回街坊完成分炉交接与新约，最后回檐下看见改变。

主线一个完整公共终局，四条可并行人物收束。没有第四章悬念，没有读对白、等待 API 或离线时继续推进的失败倒计时。失败重试本战，不撤销已经完成的前段、奖励和私人决定。

## 人物与结局

- 三娘：禁忌与共同未来。婚籍、公开程度承接第二章；炉前值房与事后住处提供实际相处空间，不强制婚礼、公开秘密或重新被丈夫带走。
- 阿念：纯白与共同游历。雪线远眺、一起拨动旧站风向片、回家后仍能再次出门；不靠突然当领袖、牺牲或认错证明成长。
- 扣子：并肩登炉与互相接应。不是每次都跌落等救；她的手艺改变路线，保留她对自己住处和私路的安排。
- 老白：共同经历后的归属。在返城与通行中发挥熟门熟路的作用；已经离岗的不强行复职，结尾给他桌边的位置，不以战死收尾。

公共结局：古炉停止旧式强烧，剩余可用晶材转入各坊炉组，旧回流接入新的供热结构；檐下成为正式街坊，基本居住与配暖不依附男性户主或在册担保。新安排由实际接管维护的工班、住户与原官署落实，不以击败一人自动抹除全部旧债或人物矛盾。主线后仍可探索、交谈，模型获得的是胜利后的现况。

## 战斗与场景

四组场景为炉城上层、雪线旧站、炉下旧城、炉心；与既有分暖站、南街和檐下相连。比例、建筑、远景、声音与阶段变化承担气势，只运行当前场景。

旧站小首领教会辨认环形破口与泄热线；雪谷拦截组合远近威胁。运输平台和检修架分别考验编队与场地，任选其一可抵达整备点。最终承火架分为重甲压阵、接入炉心、过载决燃；外接装置可拆，直接攻击本体也能取胜。单血条、不锁血、不强制复活，伤害与预警共用几何。高阶构筑允许压缩阶段。

成长仍为六槽、单件最高三级；终章提供新组合与补齐机会，不扩张等级或另设战力。各节点只发一次，不把小兵转成遗物售货机。

## 实现边界与验收

所有者为 `apps/game/expedition`，终章内容归 `content/furnace`，不增加依赖、宿主注册或外部服务。已确认事实沿现有战役保存；目标、出口、画面与模型现况引用事实，不增建另一份任务表。场景动画和交互面板是临时态。终章删除时移除内容注册、对应战斗/表现与事件引用，并在读取边界清理终章地点和事实；不清除前两章关系、对话与收藏。

验收覆盖：从第二章实际结尾进入、无高好感也能完成公共主线；两条登炉路线；人物必须实际在场；旧私事不泄露；事件与奖励重复提交不重复结算；重试、撤退、关闭重进可恢复；结局后原地图可游玩且世界认知更新。地图入口、交互点、首领和反击位可达；六职业有合理打法。桌面与手机尺寸检查轻转场、阅读、地图发现和输入；性能与真实设备结果分别报告，不以模拟视口代替真实手机测评。
