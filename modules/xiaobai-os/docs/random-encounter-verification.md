# Dice 随机遭遇验收

日期：2026-09-15。本轮按用户确认将遭遇收简为本地抽取、消息结果、原生注入和轻标签；不再要求请求前服务器保存确认。源码与构建已更新，未提交或推送。

## 本轮删除与边界

- 删除遭遇专用保存器、待确认会话、整聊快照比较／开场白等价处理、读回确认、保存重试及其按钮、保存等待屏障。删除对应的旧保存测试和专用开场白 fixture，不保留兼容壳。
- P1 的来源是遭遇额外整聊写入与原生编辑／删除竞争。现在遭遇没有这条写入路径，不再存在那份可迟到覆盖聊天的遭遇保存请求。没有改酒馆本体、公共保存器、全局 fetch 或原生编辑／删除队列。
- P2 原来的外层群聊“等待遭遇保存”阶段也随之消失；外层仍没有新回合抽取资格。群聊抽取和首回复归属继续由内层实际消息事件确定。
- 行动检定的骰点保存／同楼续写、两个设置开关的 OS 文件保存，以及用户显式清理 Dice 数据的保存契约均未借此改变。这里的“无额外保存”指随机遭遇判断与注入，不是承诺整个 OS 永不写文件。

## 当前行为

每个合格的新用户回合进行一次互斥抽取：高 1%、中 3%、低 5%、不触发 91%；触发后两个真实用户回合冷却。命中、未命中和冷却结果都直接记在当前用户消息的 `extra.xiaobaiOsDice`，不保存第二份聊天快照或冷却计数。

普通重生成、swipe、continue 复用本轮结果。命中时通过原生 SYSTEM／IN_CHAT／D1／scan=false 注入事件前缀、本档基础句、场景要求、按世界／总结开关拼接的可选参考与格式／保密要求；请求组装后清除自有注入。三档文案按用户确认更新，概率、Prompt 位置及世界／总结只读开关的联动规则未改，不增加模型调用。

本地确定触发后显示用户楼层内的命运标签；它表示本轮影响等级，不表示服务器保存回执或剧情已落实。历史标签不重播入场，关闭遭遇保留历史，停用整个 OS 则卸载其自绘 UI。记录损坏／准备失败仍可显示局部错误，不再误导用户“核实并重试保存”。

记录随酒馆正常保存聊天保留。主生成失败后，本页仍沿用原结果；若酒馆尚未保存就刷新，未保存结果可能丢失，历史缺失记录时不补抽。这个边界不再通过额外整聊保存、阻塞请求或重试队列来扩大处理。

## 提示词文案调整（2026-09-15）

- 三档按用户确认区分：低影响融入当前互动、可忽略且不另起事件；中影响提供新的可回应情况，并保留当前互动空间；高影响明显改变局面，但不替用户决定或直接结算重大后果。
- 公共结构借鉴小白酒馆：明确随机遭遇前缀、限定本次回复、贴合场景与角色、遵守后续格式与文风、不提及指令或触发标签。参考方向保持原有开关联动，以“可选灵感”引出。

## Dice 反馈与界面文案整理（2026-09-15）

- 随机遭遇准备失败时，单聊回复和群成员轮转继续；不带入失败的遭遇指令，不重抽已记录的结果。消息处只保留简短说明，不同时显示命运标签。停止、切聊及消息变化后成功或失败的迟到结果仍不可注入。
- 行动检定移除全局报错通知。普通回复准备失败时跳过检定；已保存骰点的续写准备失败仍停止该次续写并保留原结果。主 API 拒绝或流式中断由酒馆反馈，Dice 不重复错误原文，仍提供符合条件的同骰点续写入口。
- APP 简化费用、属性、概率与冷却说明；正常加载／保存不显示恢复区，失败时使用“检查保存”“使用已保存版本”，后者保留放弃未确认 OS 修改的提醒。未改变开关、概率、冷却、持久化格式或模型提示词。
- Dice 定向 66 项、OS 全量 1011 项通过；行为测试覆盖请求是否放行、错误通知不重复、原骰点保留与重试，以及失败后切聊的迟到结果。移除碰到的固定文案断言，不新增措辞快照。
- 使用真实 Dice Vue 页面与检定卡显示器、替代宿主 I/O 的浏览器预览检查 320／1200px、深浅主题、键盘切换、保存中不显示恢复区、失败恢复，以及没有错误文本时续写按钮仍能工作；均通过。截图、探针与日志位于 `output/playwright/dice-feedback-*`。本轮未重跑真实酒馆端到端，不将预览等同于完整宿主验证；没有付费模型调用。
