# 余火：墙里灯火

本篇是第二章的产品与交付目标，不注入模型。世界事实仍归 [世界](expedition-cards/world.md)，人物内核归各自人物卡，长期关系尺度不随章节改写。战斗继承 [战斗与成长设计](expedition-combat-design.md)。

## 连续的旅程

第一章止于哨站救援与物资归还，没有进入内堡街区。本篇从已完成救援的同一旅程继续：保存人物、交谈、摘要、衣物、已知秘密、位置、职业与遗物。取消用户侧选章；新旅人仍从檐下开始，旧旅人继续实际所在位置。檐下与内堡可往返。

三娘、扣子、阿念、老白到过最高关系段后，救援收尾开放其私人线索；四线互不排斥。线索通过现场和对话可见，不检查玩家说了哪句口令。接受委托后好感下降不删除事件，态度仍随当前心理与经历形成。公共路径沿归还货物的疑点进入内堡，不要求培养好感。

## 情绪与游玩理由

同一座内堡，跟不同的人进入，要经历不同类型的故事。先建立玩家想靠近这个人的理由，再制造阻力，最后兑现相处与冒险的回报。人物的暗面是余味，不是四份必须完成的道德作业；不以认错、独立或牺牲作为统一的好结局。

三娘的主味是禁忌与成熟的分寸，阿念是纯白与直接的快乐，扣子是自由和并肩犯险，老白是市井人情里真正的交心。最高关系段开放私人邀请，不替聊天记录宣布恋爱。固定场面负责发生了什么、谁在场、有什么阻力；人物如何表达、玩家为何介入，由实际交谈留下。

## 四条人物线

### 三娘：回文家

三娘将旅人带进自己生活过十九年的地方。文守桐按旧习惯留着妻子的座位，给旅人添客席；她熟悉的家、丈夫知道的习惯，与旅人认识的她同时出现。席面先呈现这种位置的差异，药物资助在谈及去留时才构成实际牵扯，不作为赴约的主题。

路线包括：在只有双方的地方约定暂不向文家公开彼此的私事；当着文守桐的面选择与旅人离开，婚籍与异议仍在；谈妥解除婚姻；谈妥独立生活、暂保婚籍。文守桐能同意、迟疑或反对，不是只能点头的手续工具。离宅不是自动离婚，暂不公开也不是失败；以后仍能当面重新处理婚姻。已谈定的离婚与独立安排不反复撤销。

文宅与南街各有实际场面。饭后回到街上，两人有属于自己的停步处，不以另一个维修任务打断。作出去留决定后，手记仍保留尚未经历的廊下相处；不因结局事实已写入而吞掉归途。固定内容不代说告白、亲吻或替玩家牵手；已确认的关系、称呼与隐情交给模型接续。十九年婚姻、不孕秘密与三娘的暗面不会变成固定的打脸素材。

结果必须落到现状：诊棚继续在檐下，婚姻、药物份额和家庭安排按确认结果更新。只有确实解除后，原婚姻才成为来历；私下约定或公开离宅仍保留婚籍。当前处境与历史经历分开，过去的约定不覆盖后来的决定。她的既往暗面不会因亲近玩家而被抹去。

### 扣子：水下的门

扣子带玩家走她知道的另一条路：旧水线、管架、只有她认得的落脚处。两人一起扳开锈闸，从地下看到城内灯火；沿路也能发现封堵测量线正沿着她曾带人走过的路延伸。她的本事与旧交易带来的风险同时存在；不凭一张药瓶收条断言她害死了谁，也不把接受帮助写成被玩家驯服。

锈闸确实横在水道里：查看现场不会开门，玩家压住下层绞柄才留下共同开闸的经历；闸板随之升起，南街两侧的入口一同通行。开闸后再谈通路的使用范围：保留为有限知情者的私路，或将指定段交给检修者与有需要的住户使用。两种均有现实利益与暴露代价，不把她的交易洗成一直在秘密行善。实际出口随决定变化；说定后，仍可陪她走上街面兑现这趟邀请。

人物地图、现场出口与独行寻路共用知情投影：私下开放不向其他人物透露路线，公开只开放城内支段，不透露扣子住处的暗口。玩家仍可带人实际走过私路；这段亲历记入既有 `facts/knowledge` 的 `deep_route_walked`，仅同行者获得知情，离开或读档后保留。它属于旅程的长期经历，随移动原子保存，失败沿用存档恢复；重开/删除旅程一并清除，移除私路内容时在解析入口一并清理，不增表或字段。

### 阿念：一起去看看

阿念想和旅人一道看看墙里的街面。南街有拨片风车与烤饼，工坊街有桥头回声；实际走到那里才能留下共同经历，不靠对白假装逛过。桥头先由她试出回声、邀玩家一道玩，玩家可以加入，也可以先走开。归檐下后还有登记桌旁的一段收尾：她把去过的地方画在废签背面，留下属于自己的小地图。相处不自动加好感，不替玩家告白。这些轻松场面在公共复暖前后都可经历，不以纠正旧登记作为享受相处的资格。

找陈禾是沿路可介入的旧事，不是整条人物线的目的。底簿与工牌成立，秦芷就能纠正错误；不要求玩家先教会阿念忏悔。她可以说明错笔，陈禾也可以不原谅；这都不替代两人的相处。共同走过街面、在桥边试过回声，就完成这趟出游；返回檐下还有登记桌旁的归途片段。旧事另列后续，不用“未完成”持续催促玩家交道德作业。

### 老白：站到门的另一边

先让老白带玩家走熟门熟路：热水铺留着他的空碗，掌柜会翻他的旧糗事，他习惯在人前替旅人接住话。之后才有门簿清查与借签者滞留。旧账里既有他的圆滑，也有真实的人情；他过去拒过的人可以见，不作为开启结局的强制羞辱仪式。

冲突是他愿不愿意在这一次把自己留在麻烦里，让别人先走；也可以依靠熟悉的门道组织逐件核验。暂离值守是檐下内部换班，不是内堡对其撤职。他不因此变成领袖，借签者也不靠烧账簿免掉一切后果。归途能一起坐回铺前，那些熟络的话因共同经历有了不同分量。八斤承接第一章谈判或战斗的真实经历。

## 汇合：分暖站

铜管司准备封闭向檐下漏热的旧支路，优先保证在册街区。古炉确实在衰冷，但选择舍弃哪一片人仍是人的决定，不归因于一个包办全部恶事的幕后黑手。

三娘的药物安排、扣子的通路、阿念追查的寄工、老白的门簿清查各接触这个问题的一面。任何一条线和公共调查均可把玩家带到共同现场；不收集四把人物钥匙。

执闸长在前段试封时登场：他知道墙外有人，仍坚持先保在册街区。查明完好管件与回流图时，程铁生说明封支令也禁止检修班过桥。玩家打通管廊，亲手开启试流阀；压力稳定形成一次可见的小胜利，执闸长仍拒绝留出出口。试流不是新的门禁：直接过桥也能继续，现场回应按是否试过分别衔接，不冒称已验证方案；打通闸桥后再回来试流也不会重演封桥。第一章余下管件的去向由实物与收料簿证实，旧单据只承担疑点。

玩家可以为同行者、秘密通路、答应过的话或檐下去打，不预设为苍生献身。胜利后由玩家接通回流，程铁生工班负责维护；现场运行的事实不等于全体官署接受新的配暖制度。

终点是保住并修通檐下这一支可维护的回热管，有工班持续照看；檐下尚未取得稳定配暖权或集体户籍。古炉衰冷根因与名分制度的结局不在本篇解决。回檐下能看见公共炉、热水与诊棚生活的变化。

公共事件只结算一次。晚开的私人线根据已经复暖的现状展开后续，不重演停暖危机；已找到的人不会再次失踪、已开的路不会重新封闭。私人收尾不要求四条全做，公共收尾也不替玩家解决未经历的私人问题。

## 空间与生活

共享空间为内堡南街、工坊寄工街、分暖站与检修层；文宅、交接房、查验房、深水道承载私人场面。南街有可落脚的客舍。工作、住处与交谈点分开，房间具有真实入口、归属、家具与在场者；地图、碰撞、移动与模型读取同一事实。

四名旧人物仍是中心。文守桐、书吏、管工领班、执闸长和实际需要的当事人服务本章冲突，不强行扩成新攻略阵容。少量路人有劳作、行走与转身，按当前场景运行；背景生活不持续调用模型。

## 战斗与成长

本章战斗主题是换位与控制通路：先单独呈现泄压、遮挡和换边，再在闸桥和主闸组合。执闸长利用牵引线路、近身攻击和泄压通路，不是门厅盾卫加血。文守桐不是必打 Boss。旧炭库提供可选精英协同挑战。

本章四个主线成长节点：入城落脚、查明回热方案、闸桥突破、主闸胜利；一处可选节点归旧炭库。私人替代路径共享公共额度，不因多攻略人物翻倍发放。现场领取、候选保存、六槽装配、职业公平、健康重试与第一章相同。只按上章主线所得调校，不要求根庭奖励。

## 模型与确认

模型得到本人的当下处境、亲历、公开消息、可执行行动与六维心理尺度，不得到整章未来剧情。固定内容只提供事件与利益冲突，不规定人物哭、拒绝几次或发表什么宣言。

启程、去留和重大结算的回复先保持可读与可重生成，玩家确认后才落实世界变化。对白不能自行宣布地图切换或行政结果。公共消息、亲历与他人转述分开；没有离线或 API 等待期间的秘密倒计时。

现场阅读保留地图可见区域，正文独立滚动，操作与返回始终可达；在场且能交谈的人可以直接接入正常对话。开闸、试流与恢复回水先呈现现场，再由玩家实际操作；关闭查看不产生结果，失败可重试，重读不重复演出或补造目击。机关的位置、操作名、完成状态同时供地图与模型读取。短暂的阀轮、表针和闸板动效只在当前场景运行，完成即停止；读档直接恢复最终姿态，离场释放资源。

## 工程边界

- 所有者：`apps/game/expedition/`；本章定义集中在其章节内容中，共用层只处理已被两章实际使用的地图、行动、战斗和结算。
- 唯一事实：战役的确认事实与人物位置；行程、机会、结局现状、可走通路、UI 和模型资料均派生，不另存任务状态镜像。
- 长期状态：新交谈人物的历史、摘要和知情归本旅程，沿用保存事务；失败保留已有候选，不重购付费请求。随重开/删除旅程清理，不碰酒馆聊天。
- 临时状态：路径、动画、渲染、请求阶段与浮层只在运行内；不增加后台任务服务或外部依赖。
- 入口：复用游戏 App、现有余火入口与分区，不新增独立测试页或另一个游戏入口。
- 兼容：只为明确保留的现行旅程及既有受支持格式在解析入口转换；不为新实现的中间形态保留兼容分叉。
- 删除：撤本章内容与入口引用，解析入口一次处理本章位置/事件/新人物记录；必须明确保留或导出交谈与已得收藏，不在日常逻辑藏旧章节。

## 验收

- 第一章完成档自然继续，不重置姓名、性别、年龄、职业、历史、摘要、衣物、关系、收藏、旧结局或钱包。
- 公共路径、四条单独人物线、四条并行，以及主线结束后补人物线，都能成立；不得只测最理想顺序。
- 未解锁、已接受后降好感、本人不在场、战败、保存失败、重生成、关闭再进、后台恢复均不制造事实或吞掉进展。
- 主闸只打与结算一次；第二条入城线不重复奖励；没有用对白假转场、全员共享私密经历、初始婚姻覆盖新现状。
- 六职业以合法正常构筑验证关键战、危险可达性和反击窗口；桌面与手机交互、实际渲染、连续切场资源释放分别验证。
- 验证三娘各条走向的确认、重生成、私密知情与后续改变；验证阿念相处路线不强制认错、扣子共同开路、老白不靠强制羞辱开启结局。
- 规则测试验证事件和后果，浏览器检查实际入口、现场阅读与转场；人物扮演质量与游戏体验分别通过模型实聊和真人试玩评估。
