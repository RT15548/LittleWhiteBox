# 小白 OS 界面设计

## 公共约定

清透、鲜活的掌上 OS。Shell 拥有基础字体、尺度、深浅主题、桌面与导航；APP 按自身活动设计页面，不统一套成表单、仿纸面板或大圆卡。

- 保留桌面与壁纸；每个 APP 自有本地 SVG 图标，Shell catalog 只引用资源，不依赖业务 Host 是否加载成功。
- 首屏直接呈现可用内容或主操作，不放宣传封面、口号、施工状态与重复说明。
- 费用、不可逆后果、保存未知和错误恢复放在决策位置，不能随精简文案一起删除。
- 本地浏览、筛选、展开与返回不调用模型。页面、草稿、焦点、滚动和动画仅为运行内状态，除非功能明确要求跨重启恢复。
- 业务状态只读 Host 投影；详情按稳定 ID 读取当前数据，不存第二份余额、库存或任务状态。
- 公共组件只服务已有真实消费者；业务界面、文案与交互仍归对应 APP。

各 APP 的布局、资金揭晓、媒体和恢复行为只在其产品设计定义，不在本文件重复。

## 操作与无障碍

正常阅读尺度，深浅主题都有清晰焦点与对比；颜色不能是状态唯一表达。确认框管理焦点，保存期间禁止重复提交。返回恢复原列表位置及有效条目焦点，目标已删除时回到合理的页面入口。

窄屏、长文本、200% 文字、键盘、触控、软键盘、减少动态效果与空／加载／失败状态都属于正式体验。离开页面清理监听、动画和局部媒体句柄，不借 UI 卸载取消功能定义为后台的任务。

## 资源与删除

优先本地 SVG、CSS 和既有字体；不为装饰增加外部素材服务或运行依赖。重 UI 按需加载。图标和样式随 APP 目录与注册一起删除，不留下旧皮肤分支。

## 验证边界

先跑现有类型、lint、行为测试与构建，再检查正式组件的完整操作。隔离桥接和手写数据能验证界面，不能证明真实存储、Provider 质量或实体设备性能；相关验证由各功能负责。
