# 小白筑家

## 终态与当前样板

终态是奶色的 3D 微型家园：玩家亲自布置房子和庭院，小白通过真实路线入住、阅读、喝茶、赏花和晒太阳。不是叠高计分，也不是大型庄园经营。房屋是主角，保留清透天空、奶白建筑、薄荷屋顶与共享小白形象；大厅入口与小白搬家使用同一画像。

当前先验证一个有选择的建造样板，不用四个引导关卡冒充内容深度。主循环为「开工 → 连续选材 → 自由布局 → 主动交付 → 家园改建或另建一栋」。给交付标准，不给摆放答案，不按秒数、点击量或强制等待延长游戏。

最低交付条件是可用的卧室、客厅和户外一角（花园或向阳露台）。额外心愿为安静阅读、向阳露台、围合小院，所需数量由 `PROJECT_WISH_TARGET` 定义。达标不会自动结束，可以继续添建、拆改、试住，也可以只按最低标准交付。小院路线和向上扩建都须成立，不把额外奖励变成唯一图纸。交付后留下的首轮生活纪念是有限内容，不宣称长期留存已解决。

## 建造与选材

- 每个工程的配给批数、初始建材及组合由 `supply.ts` 定义。开工自动出现首批，每批三选一，选完自动出现下一批，全部选完才进入建造，不需反复打开领材入口。
- 每批出现时独立随机抽取，不看上次选择、土地种子、布局或心愿，不预排未来供应，不保底露台或满奖材料。选择不额外收费；未选的同批候选放弃，已展示候选持久化，刷新不会重抽。
- 土地、承托、通路、总预算和手头建材共同约束布局。领得多不等于可以超预算建造；没用完也可交付。拆下返还对应建材与预算，不追回已到账金币。改装也消耗目标房型建材，免费院路不占配给。
- 选择用途后点地块建造；浅框表示全部地块，不筛选推荐落点，不显示答案加号。不可建的缺角由水塘与岩石表现。非法放置就地解释，不发送写入。
- 三维坐标为 x 左右、z 前后、y 楼层。双格客厅的完整占地都需合法；上层需实体承托，同层四邻通行，每个上层连通区域自动派生真实楼梯。房间自动封顶，向上扩建自动移走相应屋顶。
- 花园在地面且露天；露台在楼上且不承托上层；院路也不承托楼层。不允许拆出悬空或断路。
- 阅读角避开门口紧邻及正上方，至少一侧朝户外。露台朝阳方向不能被同层或更高建筑遮挡。围合小院要求露天花园至少三边紧邻地面房间。继续扩建可能遮窗或挡阳光，交付资格始终按当前布局派生。
- 房间可直接邀请小白使用；不可用原因在房间上下文里显示。楼层剖面、全景、缩放、全屋复位和聚焦小白保持独立于建造规则；鼠标和手势转动与地图方向一致。
- 常驻操作只保留房子、楼层、预算、建材、交付条件与主要操作。额外心愿详情、钱包、作品册、留影、声音、规则、停工按需打开，不逐步告诉玩家下一块放哪里。

## 奖励与生活

开工费、基础奖与满奖金额仅定义于 `policy.ts`。合法卧室布局立即一次性返还基础奖。最低交付不另给奖金；主动交付时满足额外心愿才结算差额。交付确认明确已得、将得及放弃的奖金；只按最低标准交付后，不得通过免费改建补领同一工程奖金。收据记录实际发放，不按后来布局重判。

交付后配给结束，家园按原土地和有效预算自由改建，不再限制房型库存。退出改建仅切换本地模式，不重复结算。新开工程自动收藏现居旧屋；作品册满先拒绝再扣费，不覆盖用户作品。旧屋可住回改建，但不能借住回丢掉在建工程。移出作品册需要确认，已发生的钱包记录保留。

首轮生活纪念来自真实空间关系：院路通花园、阅读角侧窗邻花园、客厅直接通花园、安静且非必经通路的卧室、三面围合的露天小院。满足后主动邀请小白留下纪念物和改建预算，不靠等待、次数或付费推进。纪念物随对应房间摆放，拆掉暂时收好，添回重新出现，不重复领奖。生活活动只在可见页面运行，不在后台生产收益。

## 所有者与唯一事实

功能归属 `apps/game/building/`：

- `policy.ts`：构件规格、几何边界、奖励与当前委托参数。历史房型保留的是已付费土地及收据语义，不再作为关卡解锁表。
- `supply.ts`：配给批数、候选组合、独立随机抽取与库存；`delivery.ts`：当前最低交付及额外心愿。
- `layout.ts` / `house.ts` / `spaces.ts` / `rules.ts`：占位、连通、自动基础设施、可用生活空间与几何合法性。
- `generation.ts`：扣费前用真实几何规则认证小院、露台两条空间路线；不以随机建材筛选土地，也不保证本局领得到路线所需建材。证明方案不作为界面提示。
- `domain.ts`：命令、状态与一次性奖励；`service.ts`：原子保存、钱包事务和恢复。
- `memories.ts`：生活条件、顺序、预算与纪念物位置派生；场景层只负责表现。
- `copy.ts`：全部人类可读文案。

仅从 Game module、production runtime 和 room catalog 注册；不新增依赖，不调用模型，不读取主聊天。共享小白造型与姿态归 `brand/mascot`。地图与筑家不共享领域存档。

## 状态、恢复与生命周期

用户级 `building` 分区保存项目土地、房间、building/living/abandoned 状态、收藏标记、生活纪念、配给事实、资金收据与去重身份。付费土地必须跨重启恢复，不可按新版生成器重抽；种子和委托各存一处，其余具体土地在 `site`，由 `projectBlueprint` 组合。

配给 `supply` 归工程所有，只存已拥有建材 `owned`、待选批数 `remaining` 和当前候选 `offers`。这些是跨重启保留已领材料与已见随机结果所必需的事实；剩余库存和页面选材阶段派生，不另存阶段或未来供应表。选材时把领取、批数递减和下一批候选原子保存，第三批领取后清空候选。交付或放弃时清空配给；删除工程一并删除。选材与布局走同一版本检查、原子保存和未知结果恢复，不另设锁或缓存；未知保存不重抽已展示候选。

纪念 ID 与小屋同寿命；当前愿望、纪念物摆放和有效预算派生。原付费土地预算不变，纪念增量统一由 `projectBlueprint` 合成。完成纪念不写金币账本。

房间不重复保存为屋顶、楼梯、渲染构件和心愿进度。收据是已发生的资金事实，删除作品不删除收据。不保存关卡解锁状态。

页面、编辑模式、当前楼层、选中对象、撤销栈、镜头、对话框、动画与小白活动是临时态。选材界面由工程待选批数自动呈现，返回工作台再继续仍是原批候选。声音偏好由 Game settings 拥有。只有未确认的操作意图写本地恢复日志，用于重启后核对原请求；确认或工程替换后清除，不作为第二份存档。

未知保存冻结新操作，核对或重试同一个身份，不盲目再买工程。撤销也走正常事务，外部更新及不明保存使不可靠的页面历史失效。WebGL 失败可重载画面，声音与截图错误明确反馈。减少动态效果时直接静态呈现，隐藏页面、离开或故事生成时暂停。

## 用户作品升级与退出

当前存档为 format 7。只为用户点名保留的真实作品在 `upgrade.ts` 入口一次转换，日常逻辑仅认当前模型：

- v1/v2 用冻结历史规则还原土地，保留生活房间、原预算和账本；手动基础设施转为自动派生，必要通路一次补全。
- v3 单排布局放入三维地块中排，前后补地面庭院，不改原逐列高度与相对位置。
- v4 补空生活纪念列表，不按布局自动颁发纪念。
- v5 保留全部土地、布局、纪念和收据。已交付或放弃的项目无配给；未交付项目把原有房间加初始建材作为已拥有库存，领材从首批开始。读档不补钱。
- v6 用冻结旧规则保留所有已领材料和当时可见的候选，待选批数取旧剩余批数与当前总批数的较小值。已领五批的真实工程保留最后一批，不额外加配给。旧候选算法只在升级入口使用；后续批次按当前随机规则抽取。

历史样本覆盖用户保留的单栋改建屋、完整四栋作品及第五栋在建工程。旧奖励不重判，下一次正常保存写当前格式。旧的未确认意图（无格式、format 2/3/4）核对存储后明确退役，不在新版库存规则下自动重放；当前日志为 format 5。

删除功能前决定作品导出或丢弃策略；删除 feature 目录、三个注册、声音设置和所属分区即可退出。公共钱包已发生交易不倒扣、不改写。旧叠叠乐分区不在本任务清理范围。

## 验证边界

- 逻辑：空间和预算不变量、真实活动路线、独立随机配给、不保底露台、不抽第四批、地块缺角不可建。
- 事务：基础奖和交付差额只发一次、达标不自动结束、最低交付不能免费补奖、库存限制覆盖放置/改装/撤销、选材和交付异常重启恢复、收藏与旧作品升级不改钱。
- 浏览器：自动连续选材/建造/主动交付、两种布局、达标后继续施工、刷新与返回不重抽、库存显示、旧屋保留、手机与横屏、深浅主题、键盘与真实触控、镜头方向。
- 自动检查证明契约及可操作，不代替玩家对趣味和重玩意愿的判断。
