## 当前结构

- 所有者仍为 Dice。正文中的 `[dice:记录ID]` 是位置的唯一来源；消息／活动 swipe 的 `extra.xiaobaiOsDice` 是骰点事实来源。
- 执行请求时只原位替换请求块，块外的原文与空白逐字保留；标记与骰点沿用同一次保存，不添加持久任务或保存协调器。
- 显示层只替换对应标记。删除前缀格式化、前缀文本匹配和失败后置底；不从 DOM 反写正文。
- 单文本节点按画图的做法用片段替换标记；跨节点只接受酒馆流式淡入生成的相邻 `text_segment`，不跨代码、图片或其他元素消费内容。
- `offset`／`prefixDigest` 只核验是否还能自动续写，不参与显示位置。移动标记会移动卡片，删除标记会隐藏卡片，历史骰点不会重投或变更。
- 保存回调只处理数据确认，不重绘消息。显示层在标记缺失、该楼层没有编辑器，且宿主生成结束或当前正在揭晓时，调用宿主 `updateMessageBlock` 同步临时显示，再原位替换标记。消息编辑期间取消自动处理，不拆编辑框、不丢未提交文字。保留原生 continue、输入栏草稿保护和候选隔离。
- 原生译文仍为执行前的终结请求时，只在正文仍停于本次检定处临时替换该请求为已确认标记；不回写原文或译文。原生再次重绘也能恢复卡片；无法表示标记的同一格式化来源不反复重绘。
- 新骰点揭晓前让卡片进入聊天可见区，再执行原有 2 秒 D20 揭晓。只滚动一次，历史重绘不滚动；减少动态效果／后台页面仍直接显示静态结果。
- 本次 2026-09-15 验收时标记随原始正文进入模型上下文，未增加发送前剥离。2026-09-16 已改为仅在最终请求边界过滤标记，保留保存原文与宿主续写前缀；当前行为见 [发送过滤验收](./action-check-request-filter-verification.md)。没有新增全局定位正则，原显示正则仍只隐藏待执行请求。
- 不补写无标记的旧测试检定，不增加旧定位兼容分支。停用显示层还原标记；显式清理所选聊天时，按各候选实际拥有的记录 ID 删除正文／译文中的 Dice 标记和 Dice 字段。无记录的普通 `[dice:example]` 文本、其余原文／译文及外部字段不变。消息编辑期间拒绝清理。
