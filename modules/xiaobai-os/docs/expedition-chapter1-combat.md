# 余火：第一章战斗编排

> 统一战斗、成长、失败和性能规则见[战斗与成长设计](expedition-combat-design.md)。第一章编排已接入游戏；下文时长是体验调校目标，自动模拟不能替代真人与真实手机验收。场次与触发范围由 `content/courtyard-encounters.ts` 定义，统一数值在 `content/combat-policy.ts`，节点分配在 `content/campaign-rewards.ts`；本文不复制一份实时数值表。剧情、人物、放行与救援事实以[第一章产品设计](expedition-cards/chapter1-plan.md)为准。

## 一、本章要让玩家经历什么

从外墙的小队，走到有人指挥的哨站，再见到真正守住主闸的重装守卫。正门是阵线和远近配合；水道是狭道、换位和独立小首领。进入牢房后有完整的安静段，救人不是下一波计时器。门厅收束前面的战斗语言，根庭是主线之外的进一步挑战。

普通敌人不再逐只送遗物，遭遇也不再只有清几只散兵。教学不是保证完全不操作也能过；剧情重要处的战斗不能反而比教学更空。

本章不增加物资仓库寻物、找工具开牢门、付费补给、带血条的救援护送或回营随机伏击。八斤、常有年战败后仍可交谈，不写成被杀死；所有结果继续使用既有剧情事实。

## 二、路线与挑战边界

```text
檐下接下救援
    ↓
岔口教学战 ── 安全整备
    ├─ 正门编队／谈判 → 烽火台编队／谈判 → 门厅南侧通行廊
    │                                       ├─ 中央挑战区 → 门厅守卫
    │                                       ↕
    └─ 水道前段 → 整备 → 闸口小首领 ─────→ 牢房救援
                                            ↕
                                         小门／檐下

受困者实际返营 ＋ 门厅解封 → 营地核对物资 → 三娘收尾
门厅解封后：岔口 → 根庭（可选，不拦收尾）
```

图中的连线表达现有地图连接与目标分区，不增加瞬移出口。正门实际经门厅南廊到牢房；水道直接到牢房，再可从牢房进门厅。

### 通行不等于挑战

门厅南侧两出口之间是一条能看清的连续边廊，与中央主闸挑战区分开。人物靠边廊可去牢房，Boss 不会隔着场景中心吸引自动攻击、远程偷打或无预警开战；边廊也不能成为攻击 Boss 却免受反击的安全台。

接近中央时能先看见守卫的架势和战区边界，越过挑战边界才进入战斗。未挑战时可转身去牢房；挑战开始后敌人、玩家和攻击都属于该战区，战斗期间不能借南廊反复脱战回血。边界采用实际场地与判定，不在进地图时弹“是否迎战”的暂停菜单。

推荐先救人、回营整备再打门厅，但**不靠救援完成事实锁 Boss**。熟悉路线的玩家可以先打；胜利只完成解封，不能替尚未完成的救援/核对自动收尾。提前挑战不增加一份奖励、不暗中降敌人强度。

每个战斗段只因自己的触发区域开始，不因所在场景 `safe: false` 就整图开打。同伴跨段跟随使用现有真实移动规则；不在战斗中另买 API 调用来安排他们。

## 三、成长账本

本章新发放遗物最高二级。下表的“一次选择”指一轮三选一，选择一件新遗物或对允许的已有遗物升一级；不是三件都拿。未领取不强制堵门，原领取点保留，仍只结算一次。

| 节点标识 | 达成与领取位置 | 选择职责 | 领取后累计选择 |
| --- | --- | --- | --- |
| `c1.crossroads` | 岔口清场后，路边遗留器具匣 | 三个独立起效的基础方向，建立第一件 | 1 |
| `c1.approach` | 正门通行后侧边放还的器具，或水道前段清场后的检修架；先达成者提供 | 全为新件；常规已装配第一件时，至少一项与它形成实际联动，另有独立收益选项 | 2 |
| `c1.passage` | 烽火台通行后检修匣，或闸口小首领战后维护台；先达成者提供 | 再获新件，扩展输出、生存或技能节奏，不在此连抽同一件升级 | 3 |
| `c1.cells` | 牢房守值桌旁的扣存器具；到达即可调查，与开牢门、好感及人物返营无关 | 首次允许升级，也可选新件；供门厅前调整方向 | 4 |
| `c1.warden` | 门厅解封后主闸旁器具柜 | 主线首领奖励；新件或升级，开始提供满足来源的高阶联动 | 5 |
| `c1.roots` | 根庭挑战完成后的残存遗物 | 可选构筑延展；不是本章/下章基础门槛 | 6 |

器具点是实际可交互的领取点。它们不使用七十三号箱或物资对账的两张单子，不给本章暗线加一套证据。明确可领取的器具才有奖励标识，不把全地图所有箱子都做成空宝箱。

正门与水道的替代来源引用同一节点。首次达成后，待选内容归该节点和首次领取地点，另一路只提供通行、人物和警报方面的价值，不再次出现未领取奖励标识，也不新造第二个匣子让玩家白开。先回头走另一路、再领取原节点，不得重算候选或多领。

### 每条路线得到多少

| 走法 | 门厅前的常规成长 | 代价与差异 |
| --- | --- | --- |
| 正门全打 → 牢房 | 前四个节点 | 经阵线、远程组合与烽火压力；熄火后门厅不增援。 |
| 正门两次谈判 → 牢房 | 同上 | 少打两段编队，投入在人物关系与谈判；没有少发遗物的惩罚。 |
| 一场谈判、一场战斗 → 牢房 | 同上 | 只改变对应段的解决方式，不改变它的成长额度。 |
| 水道 → 牢房 | 同上 | 前段与路线小首领；不截断烽火就要承受门厅的有限增援。 |
| 先走一路，再补另一条 | 仍是同一组节点 | 开通路径、接触守卫或消除警报；不翻倍发主线成长。 |
| 正门到门厅直接挑战 | 常规可取得前三个节点 | 少一次牢房整备选择，属于主动提前挑战；不强制回头、不补一份临时遗物。 |

常规门厅基线为四次有效选择带来的 3～4 件遗物，至多一件在此时升到二级。不是六槽满级才开打，也不要求拿到指定传奇组合。只领到三次的提前挑战应当熟练可过，但不作为首次玩家的正常难度基线。

第一件确定方向后，第二个节点提供联动而不是全池乱抽。例如火源与燃烧扩展、冰源与碎裂、职业基础与对应收益；具体合法候选和依赖仍由 `relics.ts` 及效果定义维护，本文不再抄一份遗物效果。任何列出的联动都要在实际装备和战斗中生效，不能只凭名称相近算配套。

完成前两个节点应已**提供过**一组可辨认的联动，玩家可以选独立防御件而放弃它。第三、第四次选择让他补短板，而不是到 Boss 前才发现一直拿的是没有来源的触发器。

## 四、逐段规模与时长目标

下列时长是正常操作、该段常规成长、没有重复刷取条件下的首轮调校区间，不含聊天、赶路、领奖与休整；不是已测成绩。总耗时不靠无限增援或锁血保障。

| 战斗段标识 | 职责 | 通常已获得的成长节点数 | 目标有效交战时长 |
| --- | --- | --- | --- |
| `c1.crossroads.patrol` | 教学小队，随后短促组合 | 0 | 35～55 秒 |
| `c1.gate.formation` | 盾阵与侧翼精英编队，可谈判跳过 | 1 | 45～70 秒 |
| `c1.beacon.signal` | 远近压迫与信号干扰，可谈判跳过 | 2 | 55～85 秒 |
| `c1.waterway.approach` | 狭道前段，两个推进节拍 | 1 | 45～65 秒 |
| `c1.waterway.keeper` | 闸口路线小首领 | 2 | 70～110 秒 |
| `c1.hall.warden` | 本章主线首领 | 4；提前挑战为 3 | 110～170 秒 |
| `c1.roots.heart` | 主线之后的可选挑战 | 5 | 120～180 秒 |

“通常已获得”用于调校，不是进入关卡的战力锁。六职业允许时长差异，但不能某职业稳定比其余职业慢一倍、或只有召唤职业可以完全不动取胜。强构筑和熟练操作可以短于区间，应先确认其收益来源，而非强制延长演出。

## 五、岔口：先学会动，再感到自己变强

### 编排

1. 第一组为两名巡兵和一名弓手。巡兵从路口两侧接敌，弓手使用一条能借矮墙切断的射线；不放在遥远地图角落让玩家等他们走过来。
2. 第一组清除后，北侧通路到来一名盾卫、一名巡兵和一名投弹者。有短暂喘息，不在玩家背后贴脸刷出。盾卫重击后露侧面，巡兵追逼旅人；投弹落点要求旅人离开原位，不能让召唤物替他承接所有压力。
3. 两组属于同一教学战，中间不发遗物。第二组清完才完成岔口事实，并开放本章账本的首节点。

### 学会与公平性

先看懂直线射击和移动，再看盾卫重击的反击机会。不要求读教程或用特定职业技能；走位和基础技能都能解决。弓手的压迫不能被初始近战自动攻击抢先全部抹掉，近战又必须有可达的侧翼。

第一组允许初见时挨几下继续玩；后一组开始要求玩家换位置。完全无输入的零遗物测试不能成为六职业通用通关策略，但不为杀死站桩玩家专门给教学招式加致死伤害。

清场后岔口出口旁提供安全整备。它是已经打通的路边落脚点，不刷兵、不重复领奖；回头可以休息和调整已获得的遗物。

## 六、正门：八斤的盾阵，不是单独一块血厚的盾

照面、交谈中途离开、放行和谈崩的时机全部沿用产品设计。只有实际进入战斗，下面编排才运行；谈判不使敌人减伤或变弱。

### 编排

- 首组：八斤作为领头盾卫，另有一名巡兵、两名弓手。八斤压正面，巡兵从旁边接近；两名弓手错开射击，以门洞和侧边掩体划分射线，不同步齐射封死入口。
- 两名弓手退出战斗后，一名冲锋兵从已展示的侧门进入一次；没有其他续兵。八斤尚在时，他与冲锋兵的重招错开，不能横扫与冲锋同时盖住仅有的出口。
- 八斤正面防护在持盾期间有效，重击/盾推失手后有可利用恢复；不要求带破盾遗物。清除编队后八斤退到一旁，完成正门通行事实。

玩家要么借掩体先清后排，再对付八斤；要么抓盾的恢复打快攻，再处理射线。匕首可以绕侧，弓与炮可以改变射线，刀不能被永久推在攻击范围外。

不额外设置正门暗计时。打得慢可能更累，但不因为玩家不知道隐藏三十秒线就产生无法理解的警报惩罚。谈判成功后同样开放正门节点的器具领取点，最后一句对白看完并关闭再执行，不在回复生成中提前开门领奖。

## 七、烽火台：守住信号的人

常有年不是凭空升级出的超自然 Boss。他带领一个具有威胁的远近编队；与水道小首领职责不同，不为了对称再硬塞一只首领。

### 编排与点火

- 初始为常有年、一名盾卫、一名投弹者。常有年用有起手的瞄准射击压制，盾卫追逼，投弹者驱赶长期站定的火力点。三者按总设计的同时威胁限额错开，不同时把全部预警堆到玩家脚下。
- 盾卫退出战斗后，常有年尝试点火。他向火盆移动，现有烽火 HUD 显示一次 **6 秒**点火进度；点火期间自己停止射击。受到玩家或战斗召唤物的有效伤害即打断本次点火，并进入明显恢复；不会转头每秒再尝试。
- 每战只尝试这一次；点火完成时，从可见来路进入两名巡兵作为有限增援，并记录警报。不是立即判负，不关救援出口，也不再无穷召兵。
- 击败编队后熄灭信号，完成既有截断事实；常有年仍留在场景边缘可交谈。谈判放行则直接收起火绳，不运行上述战斗。

点火是一次可争取的减压机会，不是某职业的硬 DPS 检测：近战能从合理交战位置赶到、远程有可达射线，召唤物伤害也有效。预警只用既有主 HUD 配合真实动作，不在火盆上加重复牌子。

如果点火成功，多处理一次增援就是当前段的实际代价；之后成功熄火便消除后续门厅增援，不留不可逆隐藏惩罚。已经确认的报警事实不因战败撤销；重试时本段点火进度和增援次数随战斗重新开始，不继承上一场已用次数，也不因世界已报警而额外再来一队。

## 八、水道：更直接的路，不是更空的路

水道由两个独立战斗段组成，中间有真实清场与整备。同一张水道地图内，前段和小首领各有触发区域、战区与合法生成位置。

### 前段：跨过检修通路

1. 入口后首组为两名巡兵、一名弓手，利用渠边与柱子练习换射线；不在狭窄出生点开战。
2. 清完后向闸口推进，第二组为一名盾卫、一名投弹者、一名巡兵。投弹只覆盖局部落脚处，不能同时封住唯一可走路面；玩家可以绕柱接近或等一次落点消失后移动。
3. 两组结束确认前段完成，在检修架领取对应节点。前段未完成不能隔墙远程把小首领提前拉进来，已完成则回访不刷新。

第二组仍是前段的一部分，组间不领奖；前段失败按该段起点重试。前段后、闸口战区前有安全检修台可休整，失败重试小首领无需重复前段。局部休整点不把整张水道标为安全，不提前开放人物独自赴约穿过未清战区的路线。

### 闸口看守：路线小首领

沿用“闸口看守”的职责，不新增人物暗线或新阵营。他是能够迫使玩家读招的重装看守，而不是普通盾卫放大血条。形体、站姿与主血条表明这是小首领，具体表现沿用轻量人形资源。

首领主要招式：

| 招式 | 可见起手与危险 | 反制和回报 |
| --- | --- | --- |
| 持械前压 | 持械蓄力后向前短冲，锁定方向后不拐弯 | 横向离开路线；冲空后停顿，可从侧后输出。 |
| 近身重击 | 抬手蓄力，前方圆形落点提前显现并锁定 | 退一步或绕过攻击侧；收势时近战有完整反击窗口。 |
| 闸前重砸 | 武器举高，面前沿通道出现直线冲击预警 | 利用两侧检修空地换边；不允许伤害隔实墙或封死整条路。 |

满生命至一半，逐项展示前压与近身重击；低于一半后加入直线重砸，再与旧招交替。进入后半段时，闸口侧边一名弓手和一名巡兵进入一次；首领在他们进场期间不接着发动重砸连段。玩家可先清支援或冒险抓首领窗口，不靠无限续兵要求特定清怪流派。

没有玩家操作水位的实时解谜，也没有隔几秒全图水伤。现有水闸仍是实际通道机关，不变成找钥匙任务。小首领战胜才完成水道通行，领取路线完成节点；打开水闸、进入牢房沿用原有真实碰撞与出口。

场地必须有至少两侧可实际落脚的检修区。若现有栏、柱和闸门几何无法支持横向躲避，调整这处空间后再施工招式，不把一个大范围红条硬塞进唯一宽度的狭道。

## 九、牢房与返营：保留安静段

牢房没有额外战斗，扣存器具的节点不要求先聊任何人物，也不因先杀门厅守卫而消失。值守桌旁的安全落脚处可休整、整备；不为了发遗物而把开牢门改成战斗触发器。

开牢门时，若烽火尚未截断，发生既有警报后果；以现场声音和一次轻量行程变化让玩家知道内堡已有准备，不追加倒计时，也不自动打开大面板。带人、赴约、留守、接应、各自实际返营沿用产品规则。

回营之后可以继续聊天、安排同行，也可以沿已开小门回去挑战。途中不刷新已清敌人、不把受困者变成敌人的血条目标。

## 十、门厅：本章必须站得住的首领

### 战前与警报

南廊进入中央前有明确的安全整备处，且能看见首领。正常流程从牢房或营地来，按本章账本的常规构筑调校；不要求根庭装备。

警报有效的判定继续使用“已经报警且尚未截断”。挑战开始时确定本战的警报编排，不在战斗中调用模型、更改世界谈判结果或无限加兵。

警报存在时，第二阶段入口从两侧来路进入一名盾卫、一名弓手，合计一次；没有额外隐藏生命/攻击倍率。警报不存在则不来。这是既有路径选择的世界后果，不是因玩家谈得好就临时削弱 Boss。

### 首领节奏

三个阶段的生命边界为 65% 与 30%，是本章首轮调校设定，不是所有首领统一模板。阶段之间没有不可跳过的无敌动画、回血或生命锁；跨过多个边界只进入当前应在的阶段，不排队播放已失去意义的招式。

| 阶段 | 行为变化 | 玩家学会/执行什么 |
| --- | --- | --- |
| 稳守 | 锁向冲锋、前方落点重击、间隔明确的扇面远程攻击分别出现 | 横向躲冲锋、绕过重击、找弹面间隙；每种重招后都可接近输出。 |
| 调动 | 冲锋后接落点重砸，冲锋开始时已经显示后续落点；按警报规则接入有限增援 | 不在看到冲锋结束就贪刀；先拆弓手或冒险打首领。增援进入时首领给出调度间歇，不同时放弹幕。 |
| 失守反扑 | 保留锁向冲锋与落点重砸组合，以直线震击替代扇面射击，放弃正面持盾；连续重招后恢复更长 | 守住闪避与技能，完整躲过一套后获得本章最大的反击窗口。不是单纯把所有动作加速。 |

每轮攻击序列有明确结束姿态。重击后恢复不被一次小背刺缩短；首领不以瞬间转向抵消匕首位置收益。强输出可以在反击窗口打穿阶段，正常构筑应实际见到组合变化，而非首领还没走近就自动死了。

### 场地和失败

柱子用于切断远程射线，但不能让首领卡墙。首领能通过真实可行走路径重新接敌；不能传送到玩家脸上修寻路。远程在南廊外不能隔边界偷血；近战在中央与侧翼都有实际攻击距离。

退出血条范围、镜头遮挡或设备降帧不改变伤害。失败只重来这一场，按统一重试规则健康开局，不倒退已返营的角色、不重打正门/水道、不重抽节点候选。

胜利解封主闸，出现账本中的主线首领奖励。归还物资、营地核对、三娘收尾仍分别由原剧情规则确认，不在战斗结算时一口气替玩家全办完。

## 十一、根庭：可选挑战，强调持续换位

门厅解封后才开放；可在章节收尾前后进入，不需要为它延迟主线完成。这里检验持续危险下的位置规划，与门厅的人形连招区分。

### 编排

- 前半生命：荆棘之心交替发出地面隆起的线形根刺、带安全缺口的环形攻击。先展示走位题，不一开始便塞满毒圈。
- 后半生命：加入以玩家先前位置为落点的有限存留危险地带，并从两侧根穴召来两名追猎者一次。当前危险地带上限为两处，旧的按固定寿命消退；召唤物不掉遗物或恢复道具，不靠无限刷召唤物续命。
- 危险地带将压缩安全区时，下一次根刺/环击必须仍保留可到达通路；不能让所有地形同时成为禁区。两条绕行路径在地图碰撞上真正连通。
- 完成一轮根刺与环击后，本体收缩进入明显恢复，近战能上前打、远程能站住打。没有永久环绕本体的伤害圈把刀和匕首赶走。

环形内外边界、缺口和残留时间与伤害一致，不靠音效才能找出安全区。进入后半段不是把旧全部技能一起无间隔释放。

胜利只领取可选节点，不倒过来影响门厅难度或已完成剧情。失败可离开继续生活，不出现“主线未完成”的误导；下章入口不能以这份奖励为基线。

## 十二、章节验收

本文各处的数量、时长和机制均是验收依据，不能只用“可以通关”判断质量。通用逻辑、公平性、六职业与性能验证遵守[总设计验收](expedition-combat-design.md#九验收与调校方法)，本章追加以下场景。

### 路线、状态与奖励

- 正门全打、两关全谈判、两种混合顺序、水道直入，都可救人并收尾；普通路线在门厅前拿到同一基础额度。
- 清一条再清另一条，先达成不领取再回头，放行后再次交谈，开门后存档恢复，奖励均按节点唯一结算。谈判最后对白未关闭时不提前开通/发放。
- 前段清完、小首领失败或关闭重进，已清前段不刷新，起点生命和职业资源按重试规则恢复；阶段状态与输入重放一致。
- 正门经南廊去牢房不会误触 Boss；主动提前挑战可胜利，但不替代救援；先解封再救人、先救人再解封都按真实事实指向下一步。
- 烽火点火被打断、成功点燃、胜后熄灭、谈判截断、牢房先惊动再回头截断，均只产生规定的有限增援。聊天、暂停、后台不走战斗计时。
- 领奖与保存失败、恢复、重复确认保持同一候选；有效现行旅程升级不清记录，不把已安全地点重新武装。

### 操作与难度

- 六职业分别使用正常流程合法获得的构筑跑关键战。完全无输入的初始教学、同阶段闸口和门厅不应稳定通关；同时确认敌人真的接敌，而不是靠碰巧刷在身旁才有伤害。
- 仅持续绕圈的输入与基础读招/用技能相比，交战效率和风险应明显更差；若只绕圈便与熟练操作差不多，优先检查追击、射线和输出窗口，而非全员加血。
- 正常首次玩家允许失败，但应能说出主要死因；学习一两次后能靠相同装备明显进步，而不是被迫去找另一条路补装备。
- 前两次成长选择形成的联动在战斗中可辨认；偏防御与非最优选项也能过门厅，不能只有某两件遗物的指定答案。
- 盾、柱、狭道、召唤物、远程边界全部经合法导航测试，没有卡墙白打、隔墙偷袭、无限治疗、永冻或不可躲的预警组合。
- 正门和水道各有战斗身份：前者考验阵线与处理顺序，后者考验换位与小首领读招。不能只是相同波次换背景。

### 实际交付

从正式 Game 入口在桌面及真实手机完成至少一条连续主线，再单独覆盖另一条路线、警报门厅和根庭的最重场面。记录实际设备和性能，不只拍静止截图；镜头、触控区域、预警与角色都在动的时候仍能看清。

逐场记录实际成长、用时、受伤来源和操作变化，对照本文目标。未实测的手机表现、未跑过的职业或尚无实际内容的阶段，明确列为缺口；规则测试通过不能替代体验合格。
